Your study plan

Two semesters, one connected project

The course has a 16-week foundation-and-retrieval semester and a 16-week adaptation-and-delivery semester. Every week has a lecture chapter and a three-question written test. Labs span two weeks. The final report grows from the same documentation assistant throughout.

Dependencies

Tokenization precedes shifted next-token loss; embeddings precede attention and retrieval; attention precedes transformer training and KV-cache reasoning. Retrieval metrics precede RAG changes. Frozen evaluations precede tuning and agent comparisons. Typed tools precede model-directed execution. Versioned artifacts precede deployment, monitoring, and rollback.

Weekly workload exceptions

Default: notes/readings 2h, guided lab 2h, experiment/project 4h, test/review 2h. Week 16: review 1h, lab/evaluation 2h, semester report 3h, exam 2h, correction 2h. Week 32: review 1h, reproducibility 2h, defense/demo 3h, exam 2h, correction 2h. Other project work must fit the four-hour allocation; optional extensions replace other experiments, never expand the compulsory week.

Scope and depth

Core depth: RAG, semantic retrieval, vector database lifecycle, evaluation, SFT/LoRA, typed tools, agents, inference, MLOps/LLMOps, security and operations. Mechanism depth: attention, decoder transformers, tokenization, optimization, GPU memory and introductory CUDA. Survey depth: VAEs, GANs, diffusion, flow matching, RLHF/DPO/RLVR, MoE, multimodality and distributed training. A survey topic has a defined explanation/test or toy calculation; it does not promise a production implementation.

If you stop after one semester

Weeks 1–16 form a complete introduction with a measured RAG v1. You will not yet have completed agent delivery, fine-tuning experiments, or the full operations lifecycle. The requested complete path is the full 32 weeks; compressing all topics into 16 weeks at ten hours would require substantially less depth.

Reading protocol

Each lecture lists reference IDs mapped to links in REFERENCES.md. Required reading means the named section or concept for at most 30 minutes; stop and record questions if the paper is too dense. Optional sources provide deeper treatment. No paid textbook, API subscription, or specific GPU allocation is required for the baseline path. Model downloads require internet access and sufficient host RAM/disk.
