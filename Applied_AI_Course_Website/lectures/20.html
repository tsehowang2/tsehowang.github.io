A basic pipeline gives us observable failures

Suppose the handbook assistant handles direct questions but misses “At what time can pupils board the morning transport?” The relevant passage uses bus leaves. Another failure quotes a correct time from the wrong year.

These are different problems. Semantic retrieval may help with paraphrasing. Required version filtering addresses scope. A more elaborate prompt cannot reliably repair a mislabeled source record.

Begin every change with an observed error and a hypothesis about the failed boundary. This keeps improvements connected to a task rather than a list of fashionable components.

Combining lexical and dense candidates

Lexical search can handle exact names well; dense search can handle some paraphrases. Hybrid retrieval combines candidates from both.

Scores may live on different scales. Adding a BM25 score directly to a cosine score without calibration changes the meaning unpredictably. Rank fusion combines ordering information instead.

Reciprocal rank fusion uses a sum of 1/(c+rank) over candidate lists. An absent item contributes zero from that list. The constant c controls how sharply top positions dominate.

A worked fusion comparison

Passage A is rank 1 in lexical search and rank 10 in dense search. Passage B is rank 2 in both. With c=60, A scores 1/61+1/70≈0.030679, while B scores 2/62≈0.032258.

B wins this comparison because both lists rank it consistently well. The values are rank-derived scores, not calibrated probabilities of correctness.

Changing c changes the weighting. Compare the final candidate set and downstream task result rather than judging a setting only by which passage wins one designed example.

Reranking spends more work on selected pairs

A cross-encoder can read the question and each candidate passage jointly to estimate relevance. Unlike cached bi-encoder vectors, this work happens for the query-passage pair.

Rerank a sufficiently broad candidate pool, then select a smaller evidence set. If necessary evidence never entered the pool, the reranker cannot restore it.

Measure candidate recall before reranking and answer quality afterward. The separation tells you whether failures concern finding evidence, ordering it, or using it.

Context construction after ranking

Deduplicate highly overlapping chunks, preserve source labels, and include needed exceptions. A small retrieved chunk may point to a larger parent section that supplies coherent context.

A two-version comparison needs diversity of versions, while a precise single-version question needs the requested scope. Selection depends on the task rather than a universal instruction to maximize diversity.

Pack against the actual token budget and reserve output space. Record selected source IDs and the exact packed prompt so an error can be reproduced.

Query rewriting and multi step retrieval

A conversational question such as “Does that apply next year?” may need reference resolution. A rewrite can make the intended year and subject explicit.

Rewriting can also introduce an unsupported assumption. Keep the original question, log the transformation, and preserve scope/authorization constraints independently.

Multiple retrieval steps are useful when a task needs them. They add latency and additional failure paths. Compare with a single-step baseline under a stated resource budget.

A controlled experiment

Use the same corpus, chunks, question set, version rules, generator, decoding settings, and answer rubric. Compare lexical, dense, fusion, and a reranking or selection improvement.

Save raw candidate lists and answer outputs. Slice by exact identifier, paraphrase, multi-source question, absence, and version comparison.

If one method improves paraphrases but harms exact names, investigate the pattern. Add routing only if you can define and test the rule, rather than hiding the tradeoff in an aggregate average.

Worked practice and a readiness check

Reproduce the RRF calculation, then remove a required passage from both candidate lists. Explain why increasing reranker quality cannot fix that particular absence.

Run one real RAG comparison and manually audit claims and citations. A valid source ID is only a structural check; inspect whether the cited passage supports the claim.

You are ready when you can justify one pipeline addition by a measured error reduction and state the quality, complexity, and latency costs.

Reference details and checks

Review A: Intuition

Lexical and semantic search make different errors. Hybrid retrieval combines candidate lists; reranking spends more work judging the best candidates. These are separate operations. Reranking cannot recover a relevant document absent from its candidate set.

Do not add BM25 scores directly to cosine scores without a justified calibration: their scales differ. Reciprocal rank fusion combines ranks: RRF(d) = sum_lists 1/(c + rank_list(d)) , with ranks starting at one. c controls how sharply top ranks dominate. Choose settings on development data, and compare against each component alone.

Review A: Worked fusion

With c=60, passage A ranked 1st lexically and 10th semantically scores 1/61 + 1/70 , approximately 0.03068. Passage B ranked 2nd in both scores 2/62 , approximately 0.03226. B wins because both systems support it. A document absent from one finite list contributes zero from that list. Fusion does not mean the scores are probabilities.

A cross-encoder reads question and candidate together to assign a relevance score. Rerank a sufficiently broad candidate pool, then select a small evidence set. Diversification can reduce near-duplicates, but too much diversity may discard necessary details from one source. Parent-child retrieval can search small chunks and include a larger parent section for coherent context.

Review A: Query transformation

Query rewriting resolves conversational references or expands terms. Multi-query retrieval can broaden recall. Hypothetical-document approaches generate a possible answer-like passage to embed. These can help some distributions but may introduce unsupported assumptions, extra latency and correlated false evidence. Keep the original query and log transformations. Version and access constraints must survive rewriting.

Review A: Experiment

Compare lexical only, dense only, rank fusion, and fusion plus a reranker on the same frozen development split. In the notebook, a simple deterministic reranking demonstration teaches the interface; an actual neural reranker is an optional extension, not a claimed baseline result. Report candidate recall before reranking and answer metrics after generation. This separates a recall problem from an ordering problem.

If hybrid improves identifiers but harms paraphrases, examine slice results and consider targeted routing. Do not add routing until you can explain its decision boundary and evaluation. A more complex pipeline has more timeouts, caches, artifacts and failure paths.

Exit criterion: calculate RRF, explain candidate recall, and justify whether the measured quality gain merits added latency.
