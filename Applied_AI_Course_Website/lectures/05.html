The decoder transformer

Intuition

Attention moves information across positions. A feed-forward network transforms information within a position. A transformer block combines both operations with residual connections and normalization, and stacking blocks allows progressively richer computation. The output head converts the final representation at each position into vocabulary logits.

Our teaching model uses token embeddings plus learned position embeddings. A pre-normalization block is h = x + Attention(LayerNorm(x)), followed by y = h + MLP(LayerNorm(h)). The MLP expands the channel dimension, applies a nonlinearity, and projects back. Residual paths help gradients and preserve information. Modern models may use RMSNorm, rotary position embeddings, gated MLPs or grouped-query attention; these modifications do not remove the basic information-flow picture.

Shapes and parameters

For batch B, length T and width D, the residual tensor is [B,T,D]. An MLP with expansion 4D has roughly 8D^2 weight parameters, ignoring biases. Standard multi-head attention's Q, K, V and output matrices contribute roughly 4D^2. A rough block count is therefore 12D^2; embeddings and output layers may dominate for a large vocabulary. Tied input/output embeddings reuse weights, changing the total.

For D=64 and two blocks, block matrices contain about 2*12*64^2 = 98,304 parameters. A 256-token embedding table adds 16,384. This is a tiny educational model, not an LLM. Counting parameters by summing p.numel() is the authoritative implementation check.

Position and context

Without position information, pure self-attention cannot generally distinguish permutations of the same unmasked set in the intended way. Learned absolute embeddings assign a vector to each position. Rotary position methods rotate query/key components so relative displacement influences their dot products. Do not assume a position method alone grants reliable extrapolation beyond trained context lengths.

The model outputs one logit vector per input position. During training, the logit at position t predicts the token at t+1. During inference, use the last position's logits to select the next token. For encoder-decoder models, cross-attention additionally reads encoder outputs; our tiny model has no encoder.

Experiment

Notebook 03 trains a byte-level decoder on the invented docs. Draw the block before running it, count parameters, and overfit a tiny batch as a debugging step. Then restore a held-out sequence split and report validation loss. Compare removing attention versus removing the MLP while keeping the training budget fixed. A larger model trained for more steps is not a clean architectural ablation.

Failure to recognize: generating plausible fragments from a tiny repeated corpus is not evidence of general documentation understanding. It demonstrates that the model and training loop run. Reading: R04 model architecture; optional R01 architectures lecture. Lab: 03.
