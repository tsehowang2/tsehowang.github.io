The transformer block step by step

Lecture slides · Week 10

Start with an example

Attention is one operation inside a larger computation

We can now compute contextual mixtures, but a useful model needs more than a single mixture. A transformer block combines attention with a feed-forward network, normalization, and residual connections.

Imagine each token carrying a working vector. Attention adds information from other allowed positions. The feed-forward network transforms the features at that position. Residual paths retain an additive route for the existing representation.

We will use a pre-normalization block. Other ordering choices exist; specify which one you mean before comparing code. Our goal is to trace one concrete architecture correctly.

Start with an example

The residual stream

Let x be a token representation [1,2]. Suppose an attention sublayer produces [0.5,-0.5]. Residual addition gives [1.5,1.5]. Both terms must have matching shape.

The residual connection means the block adds a learned transformation to the existing representation. It does not force the transformation to be small or guarantee that information is never lost. Later layers and projections can still change behavior substantially.

Across a sentence, the residual stream has shape [T,D], or [B,T,D] with batching. Its width stays consistent across the additions in this teaching model.

Build the mechanism

Normalization before a transformation

Layer normalization computes statistics over the feature coordinates of each token. For a simple row [2,4], the mean is 3 and variance is 1, ignoring the small numerical epsilon. Standardizing gives [-1,1] before learned affine parameters.

This operation does not average different token positions together. It therefore does not itself allow a causal model to read future words. The choice of axis is central to both the mathematics and the implementation.

Real normalization includes epsilon to avoid division problems and usually learned scale and bias. RMSNorm is a related but different operation that uses root-mean-square scaling without subtracting the mean in its basic form.

Build the mechanism

The first half of a pre norm block

Write h = x + Attention(LayerNorm(x)). Normalize the residual representation, compute masked multi-head attention, project back to width D, then add the result to x.

The query, key, and value projections operate on normalized inputs in this arrangement. The attention output still depends on the appropriate mask and position information.

Read the expression from the inside outward. The layer does not first add x to itself or normalize the entire batch as one vector. When debugging, save the normalized input and sublayer output separately.

Build the mechanism

The feed forward network

The second half is y = h + MLP(LayerNorm(h)). The MLP operates independently at each token position with shared weights. A common teaching form expands from D to 4D, applies a nonlinear activation, then projects back to D.

For D=8, a row [1,8] becomes [1,32], then [1,8]. This is a feature transformation, not another direct comparison across token positions.

Why the nonlinearity? Two linear maps without a nonlinearity compose into one linear map. A nonlinear activation permits a richer transformation. Modern models may use gated variants, but the basic separation of attention across positions and feature transformation within a position remains useful.

Build the mechanism

Stacking blocks and producing logits

One block outputs another [B,T,D] tensor. A stack of blocks repeatedly applies these transformations. The final normalized representations feed a vocabulary output projection.

For our six-token sentence and vocabulary size V, logits have shape [B,6,V]. The logit row at a position predicts the following token under next-token training.

This completes a path from IDs to embeddings, positions, contextual blocks, and vocabulary scores. Softmax over vocabulary happens at a different boundary from softmax inside attention.

Build the mechanism

Counting a small block

Ignoring biases, standard attention uses about 4D² parameters for Q, K, V, and the output projection. An MLP with width 4D uses about 8D². Together that is about 12D² per block.

At D=64, the estimate is 49152 matrix parameters per block. Two blocks give 98304. Embeddings, normalization parameters, biases, and the output head add to that count; tied embeddings change it.

Use this estimate to understand where parameters come from, then verify by summing the actual implementation's parameter sizes. A rough formula is not a replacement for inspecting the model.

Worked practice and a readiness check

Draw the full pre-norm block with two residual additions. Label the tensors before and after each operation. Explain which operations mix positions and which act independently on each token's feature row.

Given a sentence tensor [2,6,64], state why the attention and MLP outputs must return [2,6,64] before their residual additions. Then calculate the MLP's two matrix shapes [64,256] and [256,64].

You are ready to read a small transformer implementation when you can point to every part of this block and explain its role without using “the model understands” as the mechanism.

Further study 5 Intuition

Attention moves information across positions. A feed-forward network transforms information within a position. A transformer block combines both operations with residual connections and normalization, and stacking blocks allows progressively richer computation. The output head converts the final representation at each position into vocabulary logits.

Our teaching model uses token embeddings plus learned position embeddings. A pre-normalization block is h = x + Attention(LayerNorm(x)), followed by y = h + MLP(LayerNorm(h)). The MLP expands the channel dimension, applies a nonlinearity, and projects back. Residual paths help gradients and preserve information. Modern models may use RMSNorm, rotary position embeddings, gated MLPs or grouped-query attention; these modifications do not remove the basic information-flow picture.

Optional deeper study

Further study 5 Shapes and parameters

For batch B, length T and width D, the residual tensor is [B,T,D]. An MLP with expansion 4D has roughly 8D^2 weight parameters, ignoring biases. Standard multi-head attention's Q, K, V and output matrices contribute roughly 4D^2. A rough block count is therefore 12D^2; embeddings and output layers may dominate for a large vocabulary. Tied input/output embeddings reuse weights, changing the total.

For D=64 and two blocks, block matrices contain about 2*12*64^2 = 98,304 parameters. A 256-token embedding table adds 16,384. This is a tiny educational model, not an LLM. Counting parameters by summing p.numel() is the authoritative implementation check.

Optional deeper study

Further study 5 Position and context

Without position information, pure self-attention cannot generally distinguish permutations of the same unmasked set in the intended way. Learned absolute embeddings assign a vector to each position. Rotary position methods rotate query/key components so relative displacement influences their dot products. Do not assume a position method alone grants reliable extrapolation beyond trained context lengths.

The model outputs one logit vector per input position. During training, the logit at position t predicts the token at t+1. During inference, use the last position's logits to select the next token. For encoder-decoder models, cross-attention additionally reads encoder outputs; our tiny model has no encoder.

Further study 5 Experiment

notebook 12 trains a byte-level decoder on ordinary school and travel sentences. Draw the block before running it, count parameters, and overfit a tiny batch as a debugging step. Then restore a held-out sequence split and report validation loss. Compare removing attention versus removing the MLP while keeping the training budget fixed. A larger model trained for more steps is not a clean architectural ablation.
