A few notes can contribute by different amounts

Imagine three notes about a trip: where you are going, how you travel, and the weather. A question about transport should combine those notes differently from a question about rain. Attention supplies weights that determine how much each available value contributes.

For the sentence “I go to school by bus,” the representation at one position can incorporate information from earlier words. We should not assume that a particular word must receive a particular attention weight in every trained model. Our first example uses invented values so the arithmetic is visible.

The operation is a mixture of vectors. It does not necessarily select one word, return a database row, or output an explanation.

A weighted average in one dimension

Start with values [2,8,5] and weights [0.5,0.3,0.2]. The result is 0.5×2+0.3×8+0.2×5=4.4. Because the weights are nonnegative and sum to one, the result lies between the smallest and largest values.

If the weights become [1,0,0], the result is 2. If they become [0,1,0], it is 8. A soft mixture allows several inputs to contribute rather than making a hard selection.

These scalar values have no physical unit in our example. Do not read 8 as a literal “bus meaning score.” We use arbitrary features to understand the numerical operation.

The same operation works on vectors

Let the value vectors be v1=[2,0], v2=[0,4], and v3=[2,2]. Use weights [0.5,0.3,0.2]. The first output coordinate is 0.5×2+0.3×0+0.2×2=1.4. The second is 0.5×0+0.3×4+0.2×2=1.6.

The output is [1.4,1.6]. The same weight applies to all coordinates of a given value vector. We do not independently choose a different source for each coordinate in this basic attention operation.

With weights arranged as a row [1,3] and values as a matrix [3,2], their matrix product has shape [1,2]. The matrix notation describes the same arithmetic we just performed coordinate by coordinate.

One query has one distribution over keys

The weights depend on a query and a set of keys. Think of the query as the representation asking what information is useful, and each key as the representation used to compare an available position with that query.

A score tells us how strongly the query matches a key under a chosen operation. Softmax turns the scores across keys into mixture weights. This is the softmax from week 4, but the axis has changed: there we normalized vocabulary candidates; here we normalize source positions.

That distinction prevents a common confusion. Attention probabilities over positions are not the model's final probabilities over next words. The transformer performs more computation before producing vocabulary logits.

From scores to the mixture

Suppose three scores are [ln5,ln3,ln2]. Exponentiating gives [5,3,2], so softmax gives [0.5,0.3,0.2]. Multiplying those weights by the value matrix produces the [1.4,1.6] output.

We have separated two stages: computing weights and using them to combine values. A future projection can change both the comparison features and the information being mixed.

Attention can be differentiable through the scores and values. A training loss can therefore teach parameters which mixtures improve the prediction task. We will introduce the learned Q, K, and V projections next week.

Several query positions produce a matrix

If a sentence has six tokens and each is a query, we get six rows of weights. Each row sums to one across its visible keys. With six value vectors of width d_value, the full output has shape [6,d_value].

Row i answers “How does query position i combine available values?” Column j tracks how value position j contributes to different query outputs. Swapping row and column interpretations changes the meaning of the operation.

At this stage, assume every source position is available. Week 8 will impose a causal mask so a next-token model cannot use future positions.

A small attention heatmap you can read

Here is a complete invented weight matrix for the three tokens go, school, and bus. Each row is one query and each column is a key/value position. Darker cells in the illustration mean larger weights; the numbers are the exact accessible version of the same picture. All three positions are available in this example, before introducing causal masking in week 8.

Query / key go school bus
go 0.5 0.3 0.2
school 0.1 0.8 0.1
bus 0.2 0.2 0.6

The school row has a bright 0.8 cell but still assigns 0.1 to each other position. With value vectors go=[2,0], school=[0,4], and bus=[2,2], that row produces 0.1[2,0]+0.8[0,4]+0.1[2,2]=[0.4,3.4]. The smaller cells contribute [0.4,0.2] in total; they are not absent.

Two uses of the word weight must stay separate. Projection matrices such as Wq and Wk are learned parameters saved in the model. The attention weights in this picture are computed from the current input and can change from sentence to sentence. A bright cell shows how this row mixes its values; it does not label a permanent connection strength or explain the whole final answer.

Why the mixture is useful but not a complete model

An average alone cannot represent every relationship we want. Learned projections, multiple heads, position information, nonlinear layers, and residual paths will expand the computation.

Attention weights also do not tell the whole causal story of a final answer. Values can carry different information, and later operations can transform or override it. A visually strong attention edge is evidence about that mixture, not a complete human-readable explanation of the model.

The point of beginning with a weighted average is to give the compact attention equation a concrete interpretation before we place it inside a transformer.

Worked practice and a readiness check

Recalculate the vector output with weights [0.2,0.5,0.3]. The first coordinate becomes 1.0 and the second becomes 2.6. Check that each output lies within the corresponding coordinate range of the inputs.

Then explain what happens if all three value vectors are identical. Changing the weights cannot change the mixture as long as they sum to one. This is a useful sanity check for a small implementation.

You should be able to read a weight row, identify its normalization axis, multiply it by a value matrix, and distinguish source-position weights from vocabulary probabilities. That is a substantial part of attention already.

Uniform attention and a hard choice

With three vectors, equal scores produce weights [1/3,1/3,1/3]. For [2,0],[0,4],[2,2], the output is [4/3,2]. A score change can move the mixture toward one source, but softmax usually leaves several nonzero contributions.

A hard argmax would instead select one value vector. That is a different operation with different training behavior. Attention's weighted combination lets gradients express how changing several contributions might help the final loss.

Return to the heatmap above and replace the school value with [0,40]. Its weight stays 0.8, while its contribution becomes [0,32]. The picture of weights alone stays unchanged even though the output changes substantially. Read weights and values together.
