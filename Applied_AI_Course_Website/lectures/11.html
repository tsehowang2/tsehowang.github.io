Retrieval begins with a benchmark

Intuition

A retriever must rank useful evidence, not merely related text. Exact API names and error codes favor lexical matching; paraphrased intent may favor semantic matching. Start with both kinds of questions and a simple baseline. Choose a scoring method because it addresses an observed failure, not because it has “vector” in its name.

An inverted index maps terms to matching documents. TF-IDF weights frequent-in-document but rare-in-corpus terms. BM25 additionally uses term-frequency saturation and document-length normalization. Dense retrieval encodes queries and passages into a shared vector space and compares them. A lexical baseline provides a valuable control for dense retrieval, especially on technical symbols.

Relevance and metrics

Let G be the set of relevant evidence IDs and Rk the first k returned IDs. Recall@k is |G intersection Rk| / |G|. Hit@k is one if any relevant item appears. Reciprocal rank is 1/r for the first relevant rank r, zero if none appears. When more than one passage is relevant, Hit@k and Recall@k answer different questions. NDCG can represent graded relevance and position discounts, provided the relevance labels and normalization are defined.

Worked example

If G={A,B} and the first three results are C,A,D, Hit@3=1, Recall@3=1/2 and reciprocal rank=1/2. A report calling Hit@3 “recall” hides the missing second piece of evidence. For a comparison task requiring both versions, that missing piece may make the answer impossible.

For unanswerable questions with no relevant evidence, the ordinary recall denominator is zero. Do not silently assign perfect recall. Evaluate those questions separately through refusal, false-positive retrieval or unsupported-answer measures. The starter represents their retrieval metrics as not applicable.

Experiment

Notebook 06 compares the bundled lexical retriever with actual sentence-transformer embeddings. Keep document chunks, questions, version filtering and k fixed. Include exact identifiers, paraphrases and wrong-version distractors. Save per-query ranks before computing averages; a mean can hide a systematic class of failures.

Separate model failure from ingestion failure. Inspect whether the expected passage actually exists in the index, whether truncation removed its key sentence, and whether metadata filters excluded it. For the real capstone, label enough question types that one example cannot dominate a slice. The tiny teaching fixture is a software correctness aid, not a sufficient research dataset.

Exit criterion: calculate recall, hit rate and reciprocal rank by hand, then explain a dense-versus-lexical tradeoff using a real failure. Reading: R07 and R25 concepts. Lab: 06.
