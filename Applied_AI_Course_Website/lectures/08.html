Semester 1 / Week 08

Scaling and masking attention correctly

Tutorial 08Test your understanding
Lecture slides · Week 08

Learn one step at a time.

Read each explanation, pause to predict the result, then continue. Use the arrow keys while the presentation is focused. The complete lecture reader is below.

Start with an example

A prediction must use only available information

During training we have the complete sentence “I go to school by bus.” At the position after by, the model must predict bus using the prefix, even though the training tensor contains the answer farther to the right.

A causal mask prevents a query position from attending to future positions. If indexing starts at zero, query i may use keys j≤i. The diagonal remains visible because the current input token is part of the prefix used to predict the next token.

This is an information-access rule. It is separate from whether we include a position in the loss. A padding mask, causal mask, and loss mask serve different purposes.

Start with an example

The compact attention equation

The standard single-head expression is softmax(QKᵀ/√Dk + mask)V. Read it as a sequence of operations: compare queries with keys, scale scores, remove forbidden positions, normalize each query row, and mix values.

For T positions, Q/K have shape [T,Dk], scores and weights have [T,T], and V has [T,Dv]. The output has [T,Dv].

Do not memorize the expression as an indivisible symbol. If an implementation is wrong, inspect each intermediate tensor. Tiny inputs reveal errors much more clearly than a large model's final loss.

Build the mechanism

A worked scaled example

Take q=[1,0], keys [1,0] and [0,1], and values [2,0] and [0,4]. Here Dk=2, so scores are [1/√2,0], approximately [0.7071,0].

Softmax gives approximately [0.6698,0.3302]. The mixed output is [1.3395,1.3210]. Both positions contribute.

Now suppose the second key is a future position. Set its score to negative infinity before softmax. The weights become [1,0] and the output becomes [2,0]. Masking changes the normalization as well as removing the forbidden contribution.

Build the mechanism

Why multiplying probabilities by zero is different

Suppose you compute the unmasked weights [0.6698,0.3302] and then multiply the second weight by zero. You get [0.6698,0], whose sum is not one. The output becomes [1.3395,0], which differs from the correctly masked result.

You could renormalize the surviving probabilities, but masking logits before softmax is the direct standard implementation. The important point is to understand what computation you intend.

If every key in a row is forbidden, softmax has no valid normalization. Design padding and batching so each query being evaluated has an appropriate visible key, or handle invalid rows explicitly.

Build the mechanism

Why divide by the square root

Under a simplified assumption of independent, zero-mean, unit-variance query/key coordinates, the variance of their dot product grows with Dk. Large score magnitudes can make softmax very concentrated.

Dividing by √Dk keeps the scale more controlled under that intuition. This does not guarantee that learned scores always have a particular distribution. It explains the motivation for the scaling term.

Try vectors with many random coordinates and compare score spread before and after scaling. Inspect the statistics rather than asserting that a sharper attention map is better.

Build the mechanism

Padding introduces another visibility condition

A batch may contain sentences of different lengths. We can pad shorter ones to a common length, but those padding positions should not behave like meaningful source words.

The allowed key positions must satisfy both the causal rule and the validity rule for the sequence. A future token is forbidden even if it is a real word. A padding token is not useful context merely because it lies to the left.

Loss masking then determines which target predictions count toward the objective. A correctly masked attention computation can still have a wrong loss if it trains on padding labels.

Build the mechanism

An invariant catches future leakage

Fix the model parameters and disable randomness such as dropout. Run a sequence, then change only its last token. Earlier causal outputs must remain unchanged within a stated numerical tolerance.

This property checks behavior rather than the visual appearance of a triangular matrix. Removing the mask should make the same property fail on a suitable example. That failure is evidence that the test can detect the intended bug.

A lower training loss after removing the mask may simply indicate answer leakage. It does not demonstrate a better autoregressive model.

Build the mechanism

Worked practice and a readiness check

Draw a six-by-six causal visibility table for our sentence. For query school at index 3, list the visible input tokens I, go, to, school. Explain why by and bus are not available to that query.

Then compute the first query's output in the two-position example with and without masking. State the normalization axis and verify each valid row's weights sum to one.

You are ready to place attention inside larger structures when you can trace Q, K, V, scaling, masking, softmax, and value mixing independently. The next week adds several heads and explicit position information.

Optional deeper study

Further study 4 Intuition

When reading “set timeout_ms before calling send,” the representation of “send” should incorporate useful earlier information. Attention lets every position form a weighted combination of available token representations. The weights depend on content and learned projections rather than a fixed window average.

For a single batch element with X shaped [T,d_model], compute Q=XWq, K=XWk, and V=XWv. If the head dimension is d_head, Q and K have shape [T,d_head]. Scores QK^T/sqrt(d_head) have shape [T,T]. Apply the mask, take softmax over keys for each query row, and multiply by V. The output shape is [T,d_head].

Why divide by the square root? Under a simplified independent unit-variance assumption, a dot product's variance grows with d_head. Scaling helps prevent logits from becoming so large that softmax saturates. The assumption is an intuition for the normalization, not a theorem about every learned layer.

Optional deeper study

Further study 4 Masking is part of correctness

A causal mask forbids position i from attending to positions j greater than i. Apply negative infinity to forbidden logits before softmax; multiplying probabilities by zero afterward without renormalizing does not implement the same operation. Padding masks are separate: a padded token should not become useful evidence. Test both dimensions and handle sequences with at least one valid key per query to avoid all-masked softmax rows.

Optional deeper study

Further study 4 Worked example

Take a query (1,0), keys (1,0) and (0,1), and values (2,0) and (0,4). Scaled logits are approximately (0.7071,0). Softmax gives (0.6698,0.3302), so the mixed result is about (1.3395,1.3208). If the second key is future context, causal masking changes the result to (2,0). Verify these numbers in notebook 08.

Multiple heads learn different projections, concatenate their outputs and project back into the residual stream. A head need not correspond to a simple human concept. Attention weights alone are not a complete explanation of why a model answered: values, residual connections and later layers also matter.

Optional deeper study

Further study 4 Experiment

Implement attention without an attention library. Change only the last input token and assert earlier outputs remain unchanged under the causal mask. Then remove the mask and observe the failing invariance. This test catches leakage even if training loss looks excellent. Estimate score-matrix storage for increasing T: the quadratic T dimension matters before you optimize anything.
