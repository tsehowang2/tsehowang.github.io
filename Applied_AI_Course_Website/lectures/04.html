Attention is content-dependent mixing

Tutorial 02Test your understanding
Explore the mechanism

Inside attention

Choose a query token and watch scoring, masking, softmax and value mixing.

Enable JavaScript to use this illustration. The lecture notes below explain the same mechanism.

Intuition

When reading “set timeout_ms before calling send,” the representation of “send” should incorporate useful earlier information. Attention lets every position form a weighted combination of available token representations. The weights depend on content and learned projections rather than a fixed window average.

For a single batch element with X shaped [T,d_model], compute Q=XWq, K=XWk, and V=XWv. If the head dimension is d_head, Q and K have shape [T,d_head]. Scores QK^T/sqrt(d_head) have shape [T,T]. Apply the mask, take softmax over keys for each query row, and multiply by V. The output shape is [T,d_head].

Why divide by the square root? Under a simplified independent unit-variance assumption, a dot product's variance grows with d_head. Scaling helps prevent logits from becoming so large that softmax saturates. The assumption is an intuition for the normalization, not a theorem about every learned layer.

Masking is part of correctness

A causal mask forbids position i from attending to positions j greater than i. Apply negative infinity to forbidden logits before softmax; multiplying probabilities by zero afterward without renormalizing does not implement the same operation. Padding masks are separate: a padded token should not become useful evidence. Test both dimensions and handle sequences with at least one valid key per query to avoid all-masked softmax rows.

Worked example

Take a query (1,0), keys (1,0) and (0,1), and values (2,0) and (0,4). Scaled logits are approximately (0.7071,0). Softmax gives (0.6698,0.3302), so the mixed result is about (1.3395,1.3208). If the second key is future context, causal masking changes the result to (2,0). Verify these numbers in notebook 02.

Multiple heads learn different projections, concatenate their outputs and project back into the residual stream. A head need not correspond to a simple human concept. Attention weights alone are not a complete explanation of why a model answered: values, residual connections and later layers also matter.

Experiment

Implement attention without an attention library. Change only the last input token and assert earlier outputs remain unchanged under the causal mask. Then remove the mask and observe the failing invariance. This test catches leakage even if training loss looks excellent. Estimate score-matrix storage for increasing T: the quadratic T dimension matters before you optimize anything.

Exit criterion: derive every tensor shape, reproduce the worked example, and explain why a mask bug creates misleading language-model performance. Reading: R04 attention equation and diagram. Lab: 02. Assessment: checkpoint A and weekly test.
