Tokens and the generative AI landscape

Intuition

A language model does not see words as humans do. A tokenizer maps text into integer IDs, and the model predicts IDs. The same technical identifier may occupy several tokens. Therefore context length, inference cost, sequence truncation and label alignment are token-level properties. Character count is only an estimate.

For an autoregressive model, p(x1,...,xT) = product_t p(xt | x1,...,x(t-1)). Training usually minimizes the negative log of these conditional probabilities. Generation samples or selects one token, appends it, and repeats. This objective is broader than question answering: prompts and post-training shape a general continuation model into an interface that follows instructions.

Other model families

An encoder produces contextual representations using available input; a causal decoder predicts continuations; an encoder-decoder reads one sequence and produces another. An embedding model is optimized to make representation geometry useful for a task. Its output vector is not an answer.

Generative AI also includes images, audio and video. A variational autoencoder learns a latent distribution and decoder, balancing reconstruction with regularization. A GAN trains a generator against a discriminator. A diffusion model learns to reverse corruption over noise levels. A flow model learns an invertible transformation or, in flow matching, a vector field transporting one distribution toward another. These are different modeling strategies, not alternative names for an LLM. Our deep implementation path is autoregressive text; week 31 revisits multimodal implications.

Tokenization worked example

For byte-level UTF-8 tokenization, “cat” uses three bytes while some characters use multiple bytes. A learned subword tokenizer may encode “timeout_ms” as several vocabulary entries. Neither scheme permits you to assume one token equals one word. The starter's byte tokenizer is an educational stand-in, not the tokenizer of Qwen or MiniLM.

Let a model allow 2,048 tokens. If fixed instructions use 180, history 300, retrieved evidence 1,100 and the user question 70, the input totals 1,650. Reserving 300 output tokens leaves 98 tokens of slack. Adding an apparently short code example may exceed that margin. Count the complete serialized chat template with the actual tokenizer; special tokens and role separators count too.

Practical consequences

Store raw source text as well as tokenized views. Tokenizer changes can alter chunk size and training sequences even when the source file stays identical. Keep code blocks intact where possible, avoid splitting a parameter name from its explanation, and track source offsets. A vector embedding model and a generator may have different limits and tokenizers; satisfying one limit does not satisfy the other.

Experiment: compare byte counts and real tokenizer counts for prose, code, Chinese text and long identifiers. Explain a case where a character-based chunker silently truncates evidence. Exit criterion: compute a full input/output budget and distinguish four generative model families. Reading: R01 tokenization lecture headings; R03 image generation topic. Lab: 01.
