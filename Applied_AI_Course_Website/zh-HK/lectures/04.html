Score 還不是 probability

對 prefix「I go to school by」，假設 model 產生 score：bus=2、train=1、bicycle=0。Score 可以是任何實數，不必加起來等於一，也可以是負數。如果要得到 next-token probability distribution，model 就需要作 transformation。

Softmax 把一組 score 轉成總和為一的正數。它先對每個 score 取 exponential，再除以所有 exponential 的總和。較大的 score 得到較高 probability，但 score 的大小必須相對其他候選項來看。

在這裏，logit 指 model 尚未 normalize 的 score。不要把 logit 2 解讀成 200%，也不要當成 probability 0.2。

手算 softmax

對 [2,1,0]，exponential 約為 [7.389,2.718,1]，總和是 11.107。得到的 probability 約為 [0.665,0.245,0.090]。

如果每個 score 都加 100，probability 維持不變，因為分子與分母的共同乘數會抵消。實作會在取 exponential 前，先減去最大 score，以改善 numerical stability。

對 [1000,999]，減去 1000 後得到 [0,-1]。Probability 約為 [0.731,0.269]。這樣不用計算 exp(1000)，便可得到結果，避免一般 floating-point arithmetic 出現 overflow。

預期的 token 提供 loss

假設實際 training sentence 以 train 結尾。使用未經四捨五入的 probability 0.244728，cross entropy 是 −ln(0.244728)≈1.408 nats。若 training 後 train 的 probability 變成 0.7，loss 就是 −ln(0.7)≈0.357 nats。

Loss 獎勵 model 為觀察到的 target 分配 probability，並不表示其他交通選擇全都不可能。在很多例子中，model 會在其 capacity 和 training procedure 的限制下，平衡不同 target 與 context。

過度自信的錯誤 prediction 可以帶來很高代價：target probability 0.01 的 loss 約為 4.605。因此，accuracy 並不能完整描述 training objective。兩個 model 可能選出同一個最可能 token，但為 target 分配的 probability 相差很遠。

Cross entropy、likelihood 與單位

對 observed targets y1,…,yN，maximum likelihood 會選擇令 conditional probabilities 乘積較大的 parameters。取 natural logarithm 後，乘積變成總和。因此，minimize mean negative log likelihood 和 maximize likelihood 是相同的 optimization。每個 position 的 target 是 one-hot 時，這個 negative log likelihood 就是上面使用的 cross-entropy loss。

對 target distribution p 和 prediction q，cross entropy 是 H(p,q)=−Σ p_i ln(q_i)，亦等於 H(p)+KL(p||q)。H(p) 由 target distribution 決定，是固定的；所以減少 cross entropy 亦會減少由 target 到 prediction 的 KL divergence。在單一 one-hot 例子中，H(p)=0，loss 就是 −ln(q_target)。

Natural logarithm 的 loss 單位是 nats，base-2 logarithm 則是 bits：loss_bits=loss_nats/ln(2)。四個 tokens 的 uniform choice 給出 −ln(1/4)=ln4≈1.386 nats，即剛好 2 bits。比較 reported losses 時，要保持 log base 一致。

計算 log probabilities，避免 numerical overflow

應直接使用 log_softmax，而不是把 log(softmax(logits)) 拆成兩個 numerical steps。對 logits z，logsumexp(z)=m+ln Σ exp(z_i−m)，其中 m 是最大的 logit。之後 log_softmax(z)_i=z_i−logsumexp(z)。這樣可以避免計算極大的 exponentials。

對 [1000,999]，logsumexp 約為 1000.3133，log probabilities 是 [−0.3133,−1.3133]。若第二個 token 正確，loss 便是 1.3133 nats。PyTorch CrossEntropyLoss 和 functional.cross_entropy 接收 raw logits 及 class IDs；它們已結合 log_softmax 和 negative log-likelihood 計算，所以不應先自行套用 softmax。

Score 從哪裏來

設 h 是有 d_model 個 coordinate 的 contextual vector。Vocabulary output layer 可以計算 z=hW+b，其中 W 的 shape 是 [d_model,V]，V 是 vocabulary size。每個 output coordinate 都是某個 vocabulary 項目的 score。

如果 h 的 shape 是 [1,4]，而 vocabulary 有十項，W 的 shape 就是 [4,10]，z 是 [1,10]。Softmax 沿這十個候選 score 計算。Hidden width 和 vocabulary size 描述的是不同 axis。

我們還未建立 contextual vector h。接下來幾週會解釋 transformer 如何由 token 和 position information 建立它。

Gradient 把 prediction 連到 parameter

Softmax 後接 cross entropy 時，對 logit 的 derivative 等於 predicted probability 減去 target 的 one-hot indicator。如果 train 是 target，對 [0.665,0.245,0.090] 的 derivative vector 約為 [0.665,-0.755,0.090]。

Gradient descent 會減去按比例縮放的 gradient。在 logit 層面，這個方向會降低競爭項的 score，並提高 target score。在真正 network 中，chain rule 會把 signal 經 output layer 傳回更早的 representation。

這是 learning signal，並不是手寫的語言規則，例如「by 後面永遠選 bus」。同一組 parameter 參與多個 prediction tasks，因此學習會匯集不同任務的證據。

Temperature 改變 distribution

Sampling 有時使用 softmax(z/temperature)。對 logit [2,0]，temperature 1 約得到 [0.881,0.119]，temperature 2 約得到 [0.731,0.269]。在這個例子中，較大 temperature 令 distribution 較平坦。

這裏的 temperature 是 inference 的選擇。它不會重寫 training collection，也不會核實事實。Greedy decoding 直接選擇最大 logit，不應用除以 temperature 零的方法實作。

建立 transformer 之後，我們會更完整地研究 decoding。現在先理解：對同一組 score 採用不同 transformation，便可以產生不同 sampling 行為。

多個 prediction positions 的 loss

句子在每個有效 next-token position 都提供 target。如果三個 target probability 是 0.5、0.25、0.25，平均 negative log probability 就是 (ln2+ln4+ln4)/3，約 1.155。Perplexity 是 exp(average loss)，約 3.175。

Perplexity 是 exp(mean loss in nats)，亦等於 2^(mean loss in bits)。Uniform 四個 tokens 的 distribution 有 perplexity 4，因此可以把它理解為每次 prediction 的 effective branching factor。對不均勻 predictions，它是 inverse target probabilities 的 geometric mean，並非真正數出有多少個同樣可能的選項。比較 perplexity 時，必須使用相同 tokenization 和 evaluation protocol。

Padding position 不應成為普通 prediction target。訓練完整 sequence model 時，我們會分清 information mask 和 loss mask。

實例練習與學習檢查

計算 softmax([0,0,0])。每個候選項的 probability 都是 1/3。如果正確 token 是 bus，cross entropy 就是 ln3，約 1.099。解釋為何三個 score 同減一個常數，答案維持不變。

然後預測：如果只提高 bus score，其他保持不變，會有甚麼結果？要計算新的 distribution，不要只說 bus「變得更可能」。

你應該能辨認 score vector、vocabulary axis、target ID、probability distribution 和 loss。Attention 會再次用到 softmax，但用途不同：它用來決定可用 position 之間的 mixture weight。

第二個 loss 例子：兩位學生

想像兩個 model 都選 bus 為最可能 token，但真正 target 是 train。Model A 給 train 的 probability 是 0.4，model B 則是 0.01。兩者在這個例子的 top-one accuracy 都是零，但 loss 約為 0.916 和 4.605。Objective 能區分不確定與極度自信的錯誤。

現在假設下一個例子的 target 是 bus。完整比較應同時包括兩個例子，而不是只挑選有利於某個 model 的一個。要在已聲明的有效 prediction positions 上取平均 loss。

因此，學習時要把 distribution 和 target 清楚列出。最後選出的單字，會丟失 optimizer 使用的資訊。之後的 evaluation 同樣不能只靠一個好看的例子，雖然 application metric 可以與 next-token loss 不同。
