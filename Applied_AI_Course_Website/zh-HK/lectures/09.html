本課 notation

B: batch · T: tokens · d_model: model width · H: query heads · H_kv: key/value heads · d_head: query/key width per head · d_value: value width per head

只從一個角度看句子，可能並不足夠

在「I go to school by bus,」中，多種關係可能同時重要。representation 可能需要目的地、動作和交通方式的資訊。一個 attention head 會為每個 query 計算一套比較結果與 value mixing。

多個 head 為同一 layer 提供多套學到的 projection。每套都可形成不同的 mixture。我們不應假設某個 head 永遠代表「transport」，另一個代表「grammar」。這些是在訓練好的 model 中有待研究的假設，並非 architecture 預先指定的標籤。

先將多個 head 理解為平行的數值計算。它們的 output 會 concatenate，再轉換成下一個 operation 能使用的 representation。

本課程共用的 notation 表

B 是 batch size，T 是 input positions 的數量，H 是 query heads 的數量，d_model 是 residual-stream width，d_head 是每個 query/key head 的 width，d_value 是每個 value head 的 width。在標準教學 attention 中，d_value=d_head，而且 H*d_head=d_model。之後的 grouped-query model 可以讓 key/value heads 的數量 H_kv 少於 query heads 的數量 H。Vocabulary size V 與 value matrix V 是不同意思；要按周圍的 formula 或 table 分辨。

把 representation 分成多個 head 的計算

假設 model width 為 d_model=8，共有 H=2 個 head，每個 width 為 4。每個 head 為同一句子建立 Q、K、V projection。若有 T=6 個 position，一個 head 的 query shape 是 [6,4]，score matrix 的 shape 是 [6,6]。

每個 head 產生 [6,4] 的 output。將兩個 output concatenate 後得到 [6,8]。shape 為 [8,8] 的 output projection，會把這些合併的 feature 轉換成 residual stream 的 width。

head 並不是將句子分成互相獨立的詞組。兩個 head 都可以處理所有允許的 position。這裏分開的是 representation feature 和學到的 projection。

一個簡單的 concatenation 例子

對某個 token，假設 head 1 產生 [1,2]，head 2 產生 [3,4]。concatenation 得到的是 [1,2,3,4]，不是 [4,6]。若 output projection 是 identity matrix，這個 vector 便原樣通過。

假如第一個 output coordinate 改為取各個 head 第一個 coordinate 的總和，對應的 column 就可把 1 和 3 結合。學到的 output projection 讓後續 feature 整合不同 head 的貢獻。

concatenation 與 summation 是不同的 operation。reshape tensor 前，先畫出 feature axis。程式即使有看似合理的 shape，仍可能接錯 axis。

順序仍是一個獨立的要求

沒有 position 資訊的 token lookup 加上 unmasked self-attention，具有一個重要的對稱性：重新排列 token row，會令對應 output 在同一 transformation 下按相同方式重新排列。單靠把 row 從左到右畫出來，這個 operation 並不會獲得一般的詞序概念。

「The bus follows the boy」和「The boy follows the bus」需要不同的關係。position 資訊讓原本由類似 token 組成的句子，可以產生不同的 representation。

causal mask 已打破完全 unmasked attention 的對稱性：不同 position 看到不同 prefix。沒有 explicit position encoding 的 causal models，常稱為 NoPE，可以透過這種結構學到 position information。我們的教學 model 使用 learned position embeddings，而很多現代 decoders 使用 RoPE。這是 architecture 的選擇，並非每個 causal decoder 都必須有獨立 position vector 的定理。

學到的 absolute position embedding

教學 model 使用一個 position vector table。在 position t，將 token embedding 與 position embedding 相加。若兩者的 width 都是 d_model，總和的 width 也會是 d_model。

所以，即使還未進行 attention，位於 position 5 的 bus，其起始 representation 已不同於 position 1 的 bus。這次相加為後續 layer 提供 token identity 和 position 兩種資訊。

學到的 table 有預先設定的 position 範圍。超出範圍時，必須明確採用相應策略。用短例子訓練的 model，不會單憑程式接受較長 input，就自動能可靠地處理更長例子。

sinusoidal 與 rotary 的概念

sinusoidal position encoding 使用不同 frequency 的 function，而非為每個 position 學習一個 vector。原版 transformer 使用這種設計，為 position 提供有結構的數值 representation。

rotary position 方法以取決於 position 的角度，旋轉成對的 query/key coordinate。對二維的一對 coordinate，rotation 將 [x1,x2] 轉成 [x1 cosθ−x2 sinθ, x1 sinθ+x2 cosθ]。因此 relative position 可以影響 dot product 的比較。

用不同 positions 才能看到關鍵效果。先設 q=k=[1,0]，把 q 旋轉 30 度、k 旋轉 90 度。兩個 rotated vectors 約為 [0.8660,0.5000] 和 [0,1]，dot product 是 0.5。把兩個 positions 再一起移動 30 度，角度變成 60 和 120 度，dot product 仍是 0.5，因為 relative offset 仍為 60 度。若 q 保持 30 度，而 k 改為 150 度，offset 變成 120 度，dot product 就變成 −0.5。RoPE 讓 relative displacement 進入比較；真實 head vectors 使用多組 coordinate pairs 和 frequencies。

batch 與 head axis

同時處理 B 個句子時，實作可能將 query 排成 [B,H,T,d_head]。若 B=2,H=2,T=6,d_head=4，shape 就是 [2,2,6,4]。attention score 的 shape 則為 [2,2,6,6]。

softmax 沿最後的 key axis 運行，而不是跨句子或 head 進行 normalize。每個句子、head 和 query，都各有一個涵蓋可見 key 的 distribution。

value mixing 後，小心 transpose 和 reshape，回到 [B,T,d_model]。這裏適合使用各個 axis 數值都不同的測試，令意外對調一目了然。

實例練習與學習檢查

若 d_model=12,H=3,T=6,B=2，計算 d_head=4、Q shape [2,3,6,4]、score [2,3,6,6]，以及合併後的 output [2,6,12]。解釋為何增加一個 head，不一定代表增加整個 model 的 width。

追蹤 school 在兩個 position 下，使用 learned absolute embedding 所得到的起始 representation。然後描述 position vector 與 causal mask 的一項分別。

當你清楚理解 head、token、batch 和 feature axis 的意義，就可以進入下一步。我們會把 multi-head attention 放進 transformer block，再加入 residual connection、normalization 和 nonlinear transformation，完成整體結構。

親手計算 position 與 token 的相加

設 school 的 token vector 為 [1,2]。假設 position 1 的 vector 是 [0.1,0.2]，position 4 是 [-0.2,0.3]。所得起始 row 分別為 [1.1,2.2] 和 [0.8,2.3]。

兩者有相同的 token identity 部分，以及不同的 position 部分。後續學到的 projection 可以運用兩者的組合。相加這一步本身，仍未混入相鄰詞語的資訊。

建立一個有兩個 head 的 toy layer，為每個 head 配置不同的 projection matrix，再比較它們的 score row。重點是不同 parameter 容許產生不同模式，而非保證每個 head 都有整齊的人類標籤。解釋訓練好的 head 時，要分清楚例子中量度到的模式，以及對所有句子作出的普遍主張。
