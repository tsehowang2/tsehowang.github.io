Project 現在有已理解的 components

你先學會 model，才把它用於 retrieval 和 tool systems。Project 結合聚焦的 public documentation corpus、semantic search、附 source labels 的 answers、有界 executable tools、evaluation，以及可重現的 API release。

整合先由 user tasks 開始。Exact lookup、paraphrase、version comparison、troubleshooting、calculation 和 insufficient-evidence requests，各需要不同 success checks。

Architecture 應展示 evidence 和 action boundaries，而非把所有 components 藏在一次 framework invocation 後。

Tables、images 與遺失 structure

Technical pages 包含 tables、diagrams、code 和 screenshots。Text parser 可能保留 values，卻失去 row/column association。

若 table 的 product-tier labels 消失，retrieval 可找到正確 page，但 answer 把數字配到錯 tier。應把 extraction 與基於 extracted evidence 的 reasoning 分開 evaluation。

建立對機制的理解

Scaling 是選做 engineering decision

若有真正 bottleneck，選 parallelism 前先識別 resource。Data parallelism 把 model 複製到不同 batches。Tensor parallelism 分割 layer computation。Pipeline parallelism 分割 layers，再排程 microbatches。

State sharding 可減少重複 optimizer/gradient/parameter state，但增加 communication costs。Activation checkpointing 處理的是另一 memory component。

若 70% work 完美可擴展、30% serial，未計 communication 的理想 four-way speedup 為 1/(0.3+0.7/4)≈2.105。若沒實測 multiple GPUs，寫 theoretical memo 亦可。

使用已記錄 downloads 和 environment，在乾淨 directory 重現。Notebook cached variables 不應成為未記錄 dependency。

深入學習 30：直觀理解

一張 GPU 可能 memory 不足，或執行太慢。Distributed techniques 分割 data、parameters 或 computation，但 communication 亦成為 cost 的一部分。本週建立 decision framework，不要求有多張 GPUs。

Data parallelism 複製 model、處理不同 batches，並 synchronize gradients。當工作量足以攤分 communication，便可改善 throughput；但每個 replica 仍需 model state。Sharding optimizer state、gradients 或 parameters，可減少 per-device memory，但增加 communication。Tensor parallelism 分割 layers 內的 operations。Pipeline parallelism 分割 layers，再排程 microbatches，帶來 bubbles 和 coordination。

選讀：深入學習

深入學習 30：效率機制

Activation checkpointing 在 backward 期間重新計算部分 forward work，以節省 activation memory。Gradient accumulation 減少達到 effective batch 所需的 microbatch，但不會減少所有 optimizer/model state。Mixed precision 在支援情況下改變 storage 和 arithmetic；float16 可能需要 gradient scaling，bfloat16 可用性取決於 hardware。Quantization 和 adapters 處理不同 resource budget 部分。

選讀：深入學習

深入學習 30：Scaling 估算實例

在相同 global batch 下，若一張 device 每步 100 ms、兩張 60 ms，speedup 為 100/60，約 1.67；two-device scaling efficiency 約 83%。若 global batch 改變，報告每秒 examples 或 tokens，以及改變了的 optimization conditions。只比較 step times，會混合不同工作量。

另一例子：若 70% time 可完美擴展，30% 不可，four-way ideal speedup 是 1/(0.3+0.7/4) ≈ 2.11。真正 communication 可令它進一步下降。這些估算是 planning aids，不是實測預測。

選讀：深入學習

深入學習 30：實驗

notebook 30 計算 memory 和 scaling estimates，並與第 23 或 19 週 one-GPU measurements 比較。寫 capacity memo：第二張 GPU 要解決哪個 bottleneck、哪些 state 仍被複製、增加哪些 communication，以及哪項實驗可驗證計劃？區分 inference model parallelism 和 training-state sharding。

完成標準： 針對指定 memory/throughput bottleneck，選擇合理 technique，並說明 costs。 閱讀材料： R01 parallelism 主題；R18。 Tutorial： 31.

深入學習 31：重溫 generative model 類別

對 diffusion，一個 forward step 可寫成 xt = sqrt(alpha_bar_t)*x0 + sqrt(1-alpha_bar_t)*epsilon 其中 epsilon 為 standard Gaussian。Training 通常教 network 預測 noise 或相關 target；sampling 按 schedule 從 noise 重複 denoise。這與 next-token autoregression 不同，但真正 systems 可能結合不同 architectures 和 representations。

VAE 學習 latent variable model，使用 reconstruction/regularization objective。GANs 使用 adversarial learning。Flow matching 學習連接 distributions 的 vector field。這些概覽概念有助閱讀 image/audio generation documentation；實作高品質 image generator 不在核心 capstone 範圍。
