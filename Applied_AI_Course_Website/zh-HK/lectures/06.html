Attention 由 weighted mixture 開始

練習 06檢查你的理解
課堂投影片 · 第 06 週

一步一步學習。

閱讀每段解說，停下來預測結果，然後繼續。選取簡報後，可用方向鍵操作。完整講義在下方。

由例子開始

幾張筆記可以有不同貢獻

想像有三張旅程筆記：目的地、交通方式和天氣。問交通問題時，結合筆記的方式，應與問下雨的問題不同。Attention 提供 weight，決定每個可用 value 貢獻多少。

在「I go to school by bus」中，某個 position 的 representation 可以吸收較早單字的資訊。不應假設每個訓練好的 model，都必然給某個字特定的 attention weight。第一個例子使用虛構 value，讓計算過程清晰可見。

這項操作是 vector 的 mixture。它不一定只選一個字，不一定傳回 database row，也不一定輸出解釋。

由例子開始

一維 weighted average

由 value [2,8,5] 和 weight [0.5,0.3,0.2] 開始。結果為 0.5×2+0.3×8+0.2×5=4.4。因為 weight 非負而且總和為一，結果會介乎最小與最大 value 之間。

如果 weight 變成 [1,0,0]，結果是 2；如果變成 [0,1,0]，就是 8。Soft mixture 讓多個 input 作出貢獻，而不是作 hard selection。

例子中的 scalar value 沒有物理單位。不要把 8 看成字面上的「bus meaning score」。我們用任意 feature 來理解數值運算。

建立對機制的理解

相同操作也適用於 vector

設 value vector 為 v1=[2,0]、v2=[0,4]、v3=[2,2]，weight 為 [0.5,0.3,0.2]。第一個 output coordinate 是 0.5×2+0.3×0+0.2×2=1.4，第二個是 0.5×0+0.3×4+0.2×2=1.6。

Output 是 [1.4,1.6]。同一 value vector 的所有 coordinate 都套用同一 weight。在這個基本 attention 操作中，不會為每個 coordinate 各自選擇不同 source。

把 weight 排成 shape [1,3] 的 row，value 排成 [3,2] 的 matrix，兩者的 matrix product 就有 shape [1,2]。Matrix notation 描述的，正是剛才逐個 coordinate 做的相同計算。

建立對機制的理解

一個 query 對應一個 key distribution

Weight 取決於一個 query 和一組 key。可以把 query 想成提出「哪些資訊有用」的 representation，而每個 key 則是用來比較某個可用 position 與該 query 的 representation。

Score 表示在指定運算下，query 與 key 匹配的強度。Softmax 把 key 之間的 score 轉成 mixture weight。這就是第 4 週的 softmax，但 axis 改了：之前 normalize 的是 vocabulary candidates，現在 normalize 的是 source positions。

這個分別能避免常見混淆：position 上的 attention probability，並不是 model 最後對 next word 的 probability。Transformer 還要繼續計算，才產生 vocabulary logit。

建立對機制的理解

從 score 到 mixture

假設三個 score 是 [ln5,ln3,ln2]。取 exponential 得 [5,3,2]，所以 softmax 給出 [0.5,0.3,0.2]。把 weight 乘上 value matrix，就得到 [1.4,1.6] 的 output。

我們把過程分成兩步：計算 weight，以及用 weight 結合 value。之後的 projection 可以同時改變 comparison feature 和被混合的資訊。

Attention 對 score 和 value 可以是 differentiable。因此，training loss 可以教 parameter 哪種 mixture 能改善 prediction task。下週會介紹學習得到的 Q、K、V projection。

建立對機制的理解

多個 query position 形成 matrix

如果句子有六個 token，而每個都作為 query，就得到六行 weight。每行在可見 key 上的總和為一。若六個 value vector 的 width 是 Dv，完整 output 的 shape 就是 [6,Dv]。

Row i 回答「query position i 如何結合可用 value？」Column j 則追蹤 value position j 如何貢獻給不同 query output。把 row 和 column 的解讀調轉，會改變操作的意思。

目前先假設所有 source position 都可用。第 8 週會加上 causal mask，避免 next-token model 使用未來 position。

深入學習，檢查理解

Mixture 為何有用，卻不是完整 model

單靠 average，無法表示我們需要的所有關係。Learned projection、multiple heads、position information、nonlinear layer 和 residual path，會擴展計算能力。

Attention weight 亦不能完整交代最終答案的因果過程。Value 可以攜帶不同資訊，後續操作也可以轉換或蓋過它。圖中明顯的 attention 連線，是該次 mixture 的證據，並不是對 model 的完整人類可讀解釋。

先從 weighted average 開始，是為了在把 attention 放進 transformer 之前，先讓簡潔的 attention equation 有具體意思。

深入學習，檢查理解

實例練習與學習檢查

用 weight [0.2,0.5,0.3] 重新計算 vector output。第一個 coordinate 變成 1.0，第二個變成 2.6。檢查每個 output 是否都位於 input 對應 coordinate 的範圍內。

然後解釋：如果三個 value vector 完全相同，會怎樣？只要 weight 總和為一，改變 weight 便不會改變 mixture。這是小型實作中很有用的 sanity check。

你應該能讀懂 weight row、指出 normalization axis、把它乘上 value matrix，並分清 source-position weight 和 vocabulary probability。這已經掌握 attention 的重要部分。

深入學習，檢查理解

Uniform attention 與 hard choice

對三個 vector，相同 score 產生 weight [1/3,1/3,1/3]。對 [2,0]、[0,4]、[2,2]，output 是 [4/3,2]。改變 score 可以令 mixture 偏向其中一個 source，但 softmax 通常仍保留多個非零貢獻。

Hard argmax 則只選一個 value vector。那是另一種操作，training 行為也不同。Attention 的 weighted combination，讓 gradient 能表達改變多項貢獻如何幫助降低最終 loss。

如果 attention 圖中只有一格很亮，要先計算實際 weight，才把它描述成只選那一項。即使 weight 不高，某個 value 仍會影響 output，尤其當其 coordinate 很大時。必須一起解讀 weight 和 value。
