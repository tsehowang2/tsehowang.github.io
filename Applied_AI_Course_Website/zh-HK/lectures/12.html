一句話提供多個 supervised prediction

取 token [I,go,to,school,by,bus]。建立 input [I,go,to,school,by] 和 target [go,to,school,by,bus]。在每個 input position，model 都預測下一個 token。

這個 shift 說起來簡單，實作卻很容易出錯。若 target 等於同一 position 的 token，model 可能學會另一種容易得多的抄寫任務。即使 loss 很低，回答的也是錯誤問題。

開始長時間 training 前，先印出 ID 和 decode 後的 token 例子。明確檢查第一個和最後一個 supervised position。

forward pass 為每個 position 產生一個 vocabulary row

batch size 為 B、sequence length 為 T、vocabulary size 為 V 時，logit shape 是 [B,T,V]，target shape 是 [B,T]。cross entropy 將每個有效 row 與對應 target ID 比較。

causal mask 防止未來 input leakage。loss mask 則從平均值移除 padding 或其他不受 supervision 的 target position。兩者作用於不同邊界。

把 logit flatten 成 [B×T,V]、target flatten 成 [B×T]，只是一種實作上的便利做法，必須保留每個 row 與 target 原來的配對。

一個 training step 是一連串 operation

選一個 batch、運行 model、計算 loss、清除舊 gradient、backpropagate、按需要 clip gradient，再用 optimizer 更新 parameter。之後用更多資料重複。

AdamW 等 optimizer 會保留額外 state，遵從特定 update rule。要檢查 gradient 有否傳到 embedding table 和 attention projection，並不需要重新推導 optimizer。

定期儲存簡單紀錄：step、有效 token 數、training loss、validation loss、learning rate，以及任何數值錯誤。單一最終 loss 會掩蓋產生它的過程。

判斷品質前先 debug

one-batch overfit 實驗檢查 model 和 training loop 能否擬合一個極小且固定的 batch。這是有用的實作診斷，並非 generalization 結果。

然後恢復獨立的 validation set。validation 時關閉 dropout 和 gradient tracking，完成後回到 training mode。不小心讓 model 留在錯誤 mode，可能改變之後的行為。

檢查 loss 是否有限、gradient 是否非零。繪圖 library 不能修好未經 shift 的 target，也不能修好暴露答案的 attention mask。

學習模式與記住句子的分別

小量 school/travel 句子讓每個例子都容易理解，但重複 string 亦容易被記住。產生重疊 training window 前，先將完整例子分組切開。

包含一些 held-out sentence pattern，並準確報告它們測試甚麼。tiny model 能產生「I go to school by bus」，不代表它有廣泛 reasoning 或 documentation 專業知識。

更多資料、更大 model capacity、更多 training step 都可改變結果，但一次全部更改會令診斷困難。先從受控制的小型 configuration 開始。

loss 和 generation 反映不同事情

model 即使降低平均 next-token loss，在某個 decoding 選擇下，仍可能產生差的續寫。generation 會累積決策，亦可能走到與 training 不同的 prefix。

相反，平均表現差的 model 也可能生成一句漂亮句子。評估多個 input，儲存原始 output，不要只挑最佳示範。

tokenization 相符時，perplexity 是平均 negative log probability 的 exponential。比較不同 run 時，保持 tokenizer 和有效 token 計數一致。

batch size 與累積 gradient

若 microbatch size 為 2，於同一裝置累積 4 個同樣大小的 microbatch，effective example batch 就是 8。若要取得這些 mean 的平均值，每個 microbatch 的 loss 要先除以 4 才 backward，並只在整組累積後更新。

sequence length 不同，會令精確的 token-weighted equivalence 更複雜。有效 token 數不同的四個 mean，其平均不會自動等於一個 global token mean。

GPU memory 和 scaling 留待後面學習。本週先用小型 float32 CPU run 確立正確性，毋須大型 accelerator。

Learning-rate schedule 控制不同時間的 step size

Learning rate 是 optimizer update 中控制 step size 的 multiplier。Warmup 以較小 rate 開始，在初期 steps 逐步增加；之後的 cosine decay 再逐漸降低 rate。對一個 100-step 教學 run，可以選 peak 0.001、warmup 10 steps，並在 step 100 降至 0.0001。Linear warmup 下，step 5 是 0.0005；step 10 是 0.001；decay 中點 step 55 是 0.00055。Training 前先畫出 schedule，讓預期變化一目了然。

AdamW 保留 gradient moments 的 moving estimates，並使用 decoupled weight decay。Learning rate 為 η、decay 為 λ 時，在計入 adaptive-gradient contribution 前，decay contribution 以 1−ηλ 的 factor 縮小被選中的 weight。若 weight 是 2、η=0.01、λ=0.1，單看 decay 後的結果是 1.998。這與調低 learning rate 是兩回事。Parameter groups 常會把 biases 和 normalization weights 排除於 decay；應記錄實際 grouping。

Gradient clipping 限制送入 update 的 gradient norm，並不會修正錯誤 labels。若 gradient vector 的 norm 是 10，而 maximum norm 是 2，就把該 vector 乘以 0.2。應記錄 unclipped norm，讓重複 clipping 的情況可見。Mixed precision 在支援的 operations 使用較低 precision，並在需要時保留較高 precision。FP16 training 常用 gradient scaling 避免 underflow；BF16 的 exponent range 較闊，但仍需合適 hardware 和 kernels。先確保 labels、masks 和 loss computation 正確，再解讀 speedup。

Data mixture 和 contamination 會改變實驗

Data mixture 說明 training examples 如何被抽樣。若 school corpus 的 90% 是 bus sentences，10% 是 library sentences，validation behavior 便可能偏向交通語言。記錄 sampling weights、deduplication、document sources 和 oversampling。若 held-out question、其答案或 near-duplicate 進入 training，evaluation 便可能受 contamination 影響。先按有意義的 document 或 problem families 分組，再在各 split 內產生 paraphrases；保留一組從不控制 training 或 prompt 選擇的 final set。

實例練習與學習檢查

寫出 [3,8,2,5] 的 shifted target。若有效 target 的 probability 是 [0.5,0.25,0.25]，計算平均 loss。若某個 target 是 padding，指出應排除哪些 position。

訓練 tiny 教學 model，儲存 configuration 和 loss history，並檢查至少三個 prefix 的生成結果。用資料、capacity 或實作證據解釋一次失敗。

當你能重現一次 run、展示真正的 input-target 配對，並分辨 debug overfit test 和 held-out evaluation，就準備好了。

參考細節與學習檢查

複習 A：從 prediction 到 loss

給定 token ID x[0:T+1] ，input 是 x[0:T] ，target 是 x[1:T+1] 。對某 position 的 logit z，cross entropy 是 -log softmax(z)[target] 。language-model loss 對有效 target position 取平均。若 model 為每個正確 token 分配 probability 0.25，loss 為 -log(0.25)=1.3863 nats，perplexity 為 4。只有 tokenization 和 evaluation 條件適當相符時，perplexity 才可比較。

padding target 應忽略。日後的 SFT 亦可能忽略 prompt position，只讓 answer position 貢獻 loss。混淆 attention mask 和 loss mask 是常見 bug：前者控制資訊存取，後者控制哪些 prediction 接受 supervision。

複習 A：data quality 是工程問題

pretraining data pipeline 會 filter、deduplicate、segment 和 tokenize。重複或近似重複的 document 跨越 train/test 邊界，會令 evaluation 虛高。產生重疊 chunk 前，先按有意義的 group 邊界切分。對 documentation，一組相關 page 或 API topic，可能比任意 text span 更適合作 group。保留 version、license、origin、time 和 transformation metadata。

gradient descent 降低 training loss，但不保證得到期望的應用行為。用 training 和 validation curve 分辨 underfitting、overfitting 和實作 bug。validation 時關閉 dropout 和 gradient，但不要不小心讓 model 在下一個 training batch 仍留在 evaluation mode。

複習 A：optimization 計算例子

若 microbatch size 是 2，在同一裝置累積 8 個 microbatch 的 gradient，而且每個大小相同，effective example batch 就是 16。每個 microbatch 的 loss 先除以 8 才 backpropagate，optimizer 只 step 一次，然後清除 gradient。若 sequence length 不同，把 microbatch mean 等權平均，未必等於 global valid-token average。要求精確相等時，要計入 token 數。

Adam-style optimizer 保留 moment estimate，會增加大量 memory。learning-rate warmup 和 clipping 可穩定某些設定，但首先要驗證 label、mask 和資料。scheduler 不能修好用錯 target 的 training。若要準確 resume，儲存 optimizer state、random state、tokenizer identity 和當前 step。

複習 A：實驗

在 Tutorial 12: 訓練一個小型 transformer ，比較固定 configuration 的 train/dev loss 隨時間變化。刻意用未經 shift 的 label 訓練一次，解釋任務為何改變。先嘗試 one-batch overfit test，再用真正的 grouped split。starter 的 tiny corpus 太小，不能支持強烈統計結論；報告中應明說。
