generation 是對可能 output 建模

我們的 text model 透過重複預測 token 產生 sequence。generative AI 亦包括 image、sound 和其他 output。共同概念是學習 distribution 或 generation process，但不一定全部採用 next-word prediction。

想像一組手繪 bus 圖。classifier 可能預測圖中是否有 bus，generator 則旨在產生帶有相關結構的新 sample。

生成 image 可以看似合理，卻沒有重現特定 training image，也可以包含錯誤。與語言一樣，合理外觀和任務正確性需要分開 evaluation。

latent representation 與 decoder

autoencoder 將 input 映射到 compressed representation，再重建 input。variational autoencoder 加入 probabilistic latent formulation，以及鼓勵有用 latent distribution 的 regularization。

可以想像一個小 vector 控制圖畫數個方面，但不要假設每個 coordinate 都自動有清楚的人類標籤。network 是按 objective 學習 representation。

基本 VAE objective 平衡 reconstruction，以及將 approximate latent posterior 與所選 prior 聯繫的項目。model 便可 sample 一個 latent 再 decode。在完整 variational 推導前，先用 bottleneck 圖理解各部分作用。

adversarial learning

GAN 讓 generator 與 discriminator 對抗訓練。discriminator 在 training 設定下，學習分辨相關 training example 和 generated example；generator 則嘗試產生能挑戰它的 output。

兩個 objective 互相影響。單一看似出色的 sample，不能證明學到的 distribution 涵蓋所有重要情況。training instability 和 diversity 有限，都是需要研究的問題。

我們學這種排列，是為了將它與 token likelihood training 區分，而不是在本課程建立 production image generator。

diffusion 從 corruption 開始

取一個代表字母的簡單 eight-by-eight pattern，加入受控制的 Gaussian noise，產生逐步受損的版本。diffusion model 學習跨 noise level、與 denoising 相關的 prediction。

forward formula 可以寫成 x_t=√ᾱ_t x_0+√(1−ᾱ_t) ε，ε 是 standard Gaussian noise。coefficient 決定 signal 與 noise 的相對分量。

ᾱ=1 時，sample 是原來 signal；ᾱ=0 時，formula 產生 noise；中間值則是 mixture。展示這個 forward formula 的 slider，本身並沒有實作 learned reverse model。

具體的 scalar diffusion 計算

設 x0=2、ε=-1、ᾱ=0.64，則 √ᾱ=0.8、√(1−ᾱ)=0.6，得到 x_t=0.8×2+0.6×(-1)=1。

在這個 noising expression 下，簡單 tensor 的每個 element 都用相同計算方式。學到的 model 預測 noise 或相關 target，而 sampling 用有 schedule 的 reverse procedure。

把畫面 slider 往回拉，可以看見 noise 較少的版本，因為 visualization 仍知道原來 signal。這與學會從未知 noise 開始生成新 sample 不同。

Denoiser 學甚麼，以及 generation 如何逆向進行

Training 時，我們知道 clean example x_0。抽樣 noise level t 和 Gaussian noise ε，以 forward formula 建立 x_t，再要求 network ε_θ(x_t,t) 預測該 noise。常見的 simplified loss 是 ε 與 ε_θ 之間的 mean squared error。對上方 scalar example，若真實 ε 是 −1，而 prediction 是 −0.8，squared error 就是 0.04。Network 需要從大量 clean examples 和 noise levels 學習。

Generation 從一個新的 noise sample 開始，而非原本 image。在每個 scheduled step，denoiser 預測 noise 或其他 training target，sampler 再利用 prediction 建立較少 noise 的 state。在 DDPM parameterization 中，reverse mean 是 μ_θ(x_t,t)=(x_t−β_t ε_θ(x_t,t)/√(1−ᾱ_t))/√α_t，其中 α_t=1−β_t，而 ᾱ_t 是累積乘積。Reverse step 亦可能加入 schedule 指定的 random noise。這是 learned transition；沿儲存的 corrupted images 向後移動，只是 visualization。

步驟 已知或提供的內容 操作
Training x_0, t, ε 建立 x_t；預測 ε；計算 prediction error。
Sampling 開始 新的 noise sample，以及可選 condition。 由 schedule 中 noise 最多的 state 開始。
Reverse steps x_t, t, condition 預測 denoising target，再以 sampler 更新 state。

Latent diffusion 和 DiT 把概念用於不同 representation

Latent diffusion 先用 image autoencoder，把 clean image 表示為較小的 latent tensor。Diffusion training 和 sampling 在 latent space 進行，再由 image decoder 把 final latent 轉回 pixels。這減少重複 denoising work 的 spatial size，但 autoencoder 的 reconstruction quality 亦成為系統的一部分。

Diffusion Transformer，簡稱 DiT，以 transformer blocks 作為 denoising backbone，常處理 image latents 的 patches。Image-patch tokens 帶有 spatial information 和 noise-level conditioning，而非普通單字意思。用 transformer 取代 U-Net 是改變 predictor architecture，並不會令 diffusion 變成由左至右的 word prediction。

Classifier-free guidance 結合 conditional 和 unconditional predictions

對「a red school bus」這類 prompt，training conditional denoiser 時會間中移除 condition。Sampling 時，分別取得有 prompt 的 prediction ε_cond，以及沒有 prompt 的 ε_uncond。一種常見 convention 是 ε_guided=ε_uncond+w(ε_cond−ε_uncond)。在這個 convention 下，w=1 是 conditional prediction，w>1 會加強它相對 unconditional prediction 的差異。若 ε_uncond=0.2、ε_cond=0.5、w=2，combined scalar prediction 是 0.8。較大 guidance 可以改善 adherence，同時改變 diversity 或產生 artifacts；由於 APIs 的 parameterization 可以不同，應說明所用 convention。

Flow matching 學習 transport 的方向

簡單的 flow-matching 例子，以 x_t=(1−t)x_noise+t*x_data，把 noise point x_noise=−1 連到 data point x_data=2。沿這條指定直線 path 的 target velocity 是 3；t=0.4 時，point 是 0.2。Neural network 從大量 training paths 學習 velocity field，再由 ODE solver 沿 learned field 從 noise 移向 data。實際 model 會仔細選擇 paths 和 parameterizations。這個例子把 learned transport direction 與 DDPM 的 noise-prediction target 區分開。

Vision-language model 讀取 image 並產生語言

常見 VLM 連接 image encoder、projection 或 connector，以及 language model。對 school-bus photograph，image encoder 產生 visual features；connector 把它們轉成 language model 能與 text tokens 一起使用的 representations，再生成「What color is the bus?」的答案。Training 可以先 align image-text pairs，再使用 image-conditioned instructions。VLM 仍可能看錯小字、數錯物件或推斷看不到的細節，因此應分開評估 visual evidence 和 answer accuracy。

flow 概念與 multimodal token

normalizing flow 使用 invertible transformation，配合可處理的 change-of-variables formulation。flow matching 學習在 distribution 之間運送的 vector field。它們都與 generative modeling 有關，但不應視作每種 diffusion 實作的同義詞。

部分 multimodal system 使用 patch、feature 或 discrete token 表示 image/audio，再連接到 transformer component。representation 和 objective 決定 model 預測甚麼。

language-model vocabulary 與 image-patch representation 的 semantics 不同。「model 使用 token」不代表 token 對應普通詞語。

按各自回答的問題比較不同 model family

對 autoregressive text，問它建模哪個 next-token conditional，以及 generation 如何進行。對 VAE，問 latent variable、reconstruction 和 prior matching。對 GAN，問 generator-discriminator 的 training game。對 diffusion，問 forward corruption 和學到的 reverse-related prediction。

這些問題比背誦名稱清單更有意思。一個 system 可以結合數個 family 的 component。

保持範圍清晰：我們深入實作的主線仍是 text transformer。其他 family 提供概念和數值入門，並有可選的深入閱讀。

不同種類的 uncertainty

text prefix 可以有數個合理 next word；image prompt 可以容許很多有效圖畫；一句說話可以用不同聲線和節奏表達。generative modeling 必須容納變化，不能假設永遠只有一個精確 output。

所以 evaluation 取決於任務。bus fare 計算有可核實的數值答案；一張新 bus illustration 可以有很多可接受外觀，但仍可能不符合「show exactly two wheels.」的 instruction。sample 可以多樣卻錯誤，也可以準確符合狹窄要求，卻在整組中高度重複。

這解釋了為何沒有任務定義時，classification accuracy、text likelihood 和 human preference score 不能互相代替。modeling family、training objective 和 evaluation 各自回答不同問題。
