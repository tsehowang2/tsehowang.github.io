本課 notation

B: batch · T: tokens · d_model: model width · H: query heads · H_kv: key/value heads · d_head: query/key width per head · d_value: value width per head

attention 是更大計算流程中的一個 operation

我們現在懂得計算 context mixture，但有用的 model 並不只需要一次 mixture。transformer block 把 attention、feed-forward network、normalization 和 residual connection 組合起來。

想像每個 token 都帶着一個工作用的 vector。attention 加入其他允許 position 的資訊。feed-forward network 轉換該 position 的 feature。residual path 則為現有 representation 保留一條相加的路徑。

我們會使用 pre-normalization block。其他排列方式也存在；比較程式碼前，先說明你指哪一種。我們的目標是正確追蹤一個具體 architecture。

residual stream

設 x 是 token representation [1,2]，而 attention sublayer 產生 [0.5,-0.5]。residual addition 得到 [1.5,1.5]。兩項的 shape 必須相符。

residual connection 表示 block 將學到的 transformation 加到現有 representation 上。它不強制 transformation 必須很小，也不保證資訊永不流失。後續 layer 和 projection 仍可大幅改變行為。

對整個句子，residual stream 的 shape 是 [T,d_model]；有 batching 時則是 [B,T,d_model]。在教學 model 中，每次相加的 width 都保持一致。

在 transformation 前進行 normalization

layer normalization 為每個 token 的 feature coordinate 計算統計量。對簡單的 row [2,4]，忽略很小的數值 epsilon 時，mean 是 3，variance 是 1。在套用學到的 affine parameter 前，standardize 的結果是 [-1,1]。

這個 operation 不會把不同 token position 一起取平均，所以它本身不會讓 causal model 讀取未來的詞。axis 的選擇對數學和實作都十分關鍵。

實際的 normalization 會包含 epsilon，以避免除法問題，而且通常有學到的 scale 和 bias。RMSNorm 是相關但不同的 operation；基本形式用 root-mean-square scaling，而不減去 mean。

pre-norm block 的前半部分

寫成 h = x + Attention(LayerNorm(x))。先 normalize residual representation，計算 masked multi-head attention，再 project 回 width d_model，最後將結果加到 x。

在這個排列下，query、key、value projection 作用於 normalized input。attention output 仍依賴合適的 mask 和 position 資訊。

由內到外讀這個 expression。layer 不是先把 x 加到自身，也不是將整個 batch 當作一個 vector 來 normalize。debug 時，分開儲存 normalized input 和 sublayer output。

feed-forward network

後半部分是 y = h + MLP(LayerNorm(h))。MLP 使用共享 weight，在每個 token position 獨立運行。常見教學形式是從 d_model 擴展到 4*d_model，套用 nonlinear activation，再 project 回 d_model。

若 d_model=8，一個 [1,8] 的 row 會變成 [1,32]，再回到 [1,8]。這是 feature transformation，不是再次跨 token position 直接比較。

為何需要 nonlinearity？兩個沒有 nonlinearity 的 linear map，合起來仍是一個 linear map。nonlinear activation 容許更豐富的 transformation。現代 model 可能使用 gated 變體，但跨 position 的 attention 與 position 內的 feature transformation 這個基本區分仍然有用。

堆疊 block 並產生 logit

一個 block 輸出另一個 [B,T,d_model] tensor。堆疊多個 block 會重複套用這些 transformation。最後的 normalized representation 會送入 vocabulary output projection。

對我們有六個 token 的句子，若 vocabulary size 為 V，logit 的 shape 就是 [B,6,V]。在 next-token training 中，每個 position 的 logit row 預測下一個 token。

至此便完成從 ID 到 embedding、position、contextual block、vocabulary score 的路徑。涵蓋 vocabulary 的 softmax，與 attention 內部的 softmax，位於不同的計算邊界。

計算小型 block 的 parameter

對這個指定的教學 block，先忽略 biases 和 normalization parameters。當 H*d_head=d_model 時，標準 MHA 的 Q、K、V 和 output projection 合共有 4*d_model² 個 matrix parameters。兩個 matrix 的 MLP，若 hidden width d_ff=4*d_model，就有 2*d_model*d_ff=8*d_model² 個 parameters，合計 12*d_model²。這條 formula 只適用於這種 attention 和 MLP 組合，並非所有 transformer blocks。

當 d_model=64，估計每個 block 有 49152 個 matrix parameter，兩個 block 有 98304 個。embedding、normalization parameter、bias 和 output head 還會增加數目；tied embedding 亦會改變總數。

用這個估算理解 parameter 來自哪裏，再透過實際實作中各 parameter size 的總和驗證。粗略 formula 不能取代檢查 model。

GQA 和 SwiGLU 會改變 parameter count

GQA 保留 H 個 query heads，但共享 H_kv 個 key/value heads。當 d_head=d_model/H，且 value widths 相同時，attention matrix count 為 2*d_model²+2*d_model*H_kv*d_head：一個 full-width query projection、較小的 key/value projections，以及一個 full-width output projection。若 d_model=64、H=8、H_kv=2、d_head=8，attention parameters 是 10,240 個；MHA 則是 16,384 個。

SwiGLU 使用三個 matrices：兩個把 input project 至 d_ff，其中一條 branch 經過 SiLU，兩條 branch 逐 coordinate 相乘，再由第三個 matrix project 回 d_model。其 matrix count 為 3*d_model*d_ff。若 d_ff=4*d_model，單是 MLP 已有 12*d_model² 個 parameters。若 d_ff 約為 (8/3)*d_model，count 便接近教學 MLP 的 8*d_model²；實作通常會為 efficient kernels 把 width 取整。比較時應配對 parameter budgets，而非默認每個 MLP 都 expand 四倍。

參考細節與學習檢查

複習 A：直觀理解

我們的教學 model 使用 token embedding 加 learned position embedding。pre-normalization block 是 h = x + Attention(LayerNorm(x)) ，接着是 y = h + MLP(LayerNorm(h)) 。MLP 擴展 channel dimension，套用 nonlinearity，再 project 回來。residual path 有助 gradient 傳遞及保留資訊。現代 model 可能使用 RMSNorm、rotary position embedding、gated MLP 或 grouped-query attention；這些修改並不會移除上述基本資訊流。

複習 A：shape 與 parameter

對這個標準 MHA 加兩個 matrix 的 MLP，residual tensor 是 [B,T,d_model]，matrix parameters 約為 12*d_model²。若使用 GQA 或 gated MLP，便要按上方 formulas 計算實際 projection shapes。Embedding 和 output-head parameters 需要另計；weight tying 會改變它們合計的數量。

對 d_model=64 及兩個 block，block matrix 大約包含 2*12*64^2 = 98,304 個 parameter。一個 256-token embedding table 再增加 16,384 個。這是小型教學 model，不是 LLM。將 p.numel() 的總和，才是實作上的權威檢查。

複習 A：position 與 context

model 為每個 input position 輸出一個 logit vector。training 時，position t 的 logit 預測 t+1 的 token。inference 時，用最後一個 position 的 logit 選出下一個 token。encoder-decoder model 的 cross-attention 還會讀取 encoder output；我們的 tiny model 沒有 encoder。

複習 A：實驗

Tutorial 12: 訓練一個小型 transformer 以普通 school 和 travel 句子訓練 byte-level decoder。執行前先畫 block、計算 parameter，並以 tiny batch overfit 作 debug。然後恢復 held-out sequence split，報告 validation loss。在 training budget 固定下，比較移除 attention 和移除 MLP 的結果。更大的 model 加上更多 training step，並不是清晰的 architecture ablation。

要辨認的失敗： 從少量重複 corpus 產生看似合理的片段，並非普遍理解 documentation 的證據。它展示的是 model 和 training loop 能運行。 閱讀材料： Vaswani et al. Attention Is All You Need (R04) model architecture；可選讀 Stanford CS336 Language Modeling from Scratch (R01) architecture lecture。 Tutorial： 10.
