本課 notation

B: batch · T: tokens · d_model: model width · H: query heads · H_kv: key/value heads · d_head: query/key width per head · d_value: value width per head

Row 和 column conventions 表達相同 map

Attention 章節把 token vectors 儲存為 rows：y_row=x_row*W_row。第 25 週使用 column vectors，以配合常見 LoRA formula：y_col=W_col*x_col。兩者是同一計算的 transpose：x_col=x_row transpose、W_col=W_row transpose。因此 row convention 的 [d_in,d_out] matrix 會成為 column convention 的 [d_out,d_in]。H_kv 留待 grouped-query/cache 部分使用；本節普通 attention 每個 query head 都有一組 K/V。

同一 token 可以擔任多個計算角色

上週我們手動選擇 attention weight。Transformer 需要從 representation 計算 weight。以「I go to school by bus」的六行為例。每行由 token representation 開始；在之後的完整 model 中，還會加入 position information。

Attention 用 learned linear transformation，從每行建立 query vector、key vector 和 value vector。它們是同一起始 representation 的不同視角，為計算中的不同角色而優化。

Query、key 和 value 是角色名稱，並不分別代表人手寫的問題、字典定義和事實答案。把名稱與自然語言的字面意思分開，會更容易推理這個機制。

用看得見的數字做 linear projection

設一個 input row 為 x=[1,2]。Wq 為 identity matrix，Wk=[[1,0],[0,0.5]]，Wv=[[2,0],[0,1]]。用 row-vector notation 計算，q=xWq=[1,2]、k=xWk=[1,1]、v=xWv=[2,2]。

Input row 相同，但 projection 後的 vector 不同。訓練好的 model 中，這些 projection matrix 是隨 loss 改變的 parameter。我們只是為了方便逐項檢查乘法，才選擇簡單 matrix。

改變 Wk，會改變該 position 如何參與比較。改變 Wv，則會改變 weight 計算完成後所貢獻的資訊。這兩種影響可以分開研究。

Attention dimensions 的共用 notation

本課程以 d_model 表示 token-representation width，d_head 表示一個 query/key head width，d_value 表示一個 value-vector width。T 是 positions 數目，B 是 batch examples 數目，H 是 heads 數目。普通 equal-width multi-head attention 中，d_head=d_value=d_model/H；下面的 single-head shape 練習則刻意容許 value width 不同。這些 symbols 命名 dimensions，而不是不同種類的 vectors。

對整個句子套用 projection

如果 X 的 shape 是 [T,d_model]，Wq 是 [d_model,d_head]，Wk 是 [d_model,d_head]，Q 和 K 的 shape 都會是 [T,d_head]。Wv 可以是 [d_model,d_value]，產生 shape [T,d_value] 的 V。

同一 projection matrix 會套用於每個 token position。一般 self-attention 不會為第一個字訓練一個 Wq，再為第六個字訓練另一個。共享 parameter 讓這項操作能處理不同 sequence。

Position 數目 T 和 feature 數目 d_model 描述不同事物。X 乘上 projection 會改變 feature coordinate；這一步本身不會混合 token position。

比較所有 query-key pair

對每個 query q_i，與所有 key k_j 做 dot product。把所有 i、j 的結果排好，就得到 QKᵀ，一個 shape [T,T] 的 score matrix。

假設 T=6。用 zero-based indexing 時，entry [4,1] 描述 query position 4 與 key position 1 的比較，並不是 word ID 1 的 vocabulary score。

這是本 attention block 中，第一個明確比較不同 position 的操作。之後 weight-times-value 的乘法，才把資訊在不同 position 之間傳遞。

完整的 two-position 例子

設 Q=[[1,0],[0,1]]、K=[[1,0],[0,1]]、V=[[2,0],[0,4]]。未 scaling 的 score matrix 是 identity matrix。第一個 query 的 score [1,0]，經 softmax 後的 weight 約為 [0.731,0.269]。

它的 output 約為 [1.462,1.076]。第二個 query 有相反的 score pattern，output 約為 [0.538,2.924]。

兩個 output 都可以包含兩個 value。這項操作不會強迫每個 query 只選與自己配對的 position。第 8 週除以 sqrt(d_head) 的 scaling 會改變這些數字，而 masking 可能移除部分貢獻。

Self-attention 與 cross-attention 使用不同 source

Self-attention 的 Q、K、V 來自同一 sequence 的 representation。Cross-attention 的 query 則來自一個 sequence，key 和 value 來自另一個。

翻譯中，target 端 decoder representation 可以 query source 端 encoder representation。如果 target 長度是 U，source 長度是 T，score matrix 的 shape 就是 [U,T]，不一定是方形。

這個長方形例子很適合檢查你是否理解各個 axis。Attention 的本質，是把 query position 與 key/value position 建立關係，並不要求兩者數量相同。

Training 可以改變甚麼

Gradient 可以改變 input embedding 和每個 projection matrix。如果某項比較反覆幫助預測合適的 next token，training 就可以強化相應計算。

學到的 coordinate 不一定符合「transport head」或「school key」這類簡單說法。這些解讀需要證據。講義的小例子解釋的是合理計算，並非聲稱發現 pretrained model 的實際內部結構。

我們仍可以精確測試 implementation：projection shape、softmax 後每行的總和、output dimension，以及改變 key 或 value 的敏感程度。

實例練習與學習檢查

若 X 的 shape 是 [6,4]，d_head=2、d_value=3，寫出 projection shape [4,2]、[4,2]、[4,3]，再寫 Q/K/V 的 shape [6,2]、[6,2]、[6,3]。Score matrix 是 [6,6]，output 是 [6,3]。

Cross-attention 有四個 query、七個 key/value position 時，score shape 是 [4,7]。解釋為何每個 query 的 softmax 仍沿七個 key 計算。

繼續之前，你應能說明哪些 operation 改變 feature coordinate、哪些比較 position，以及哪些混合 value 資訊。接下來 scaling 和 masking 會完善這項計算，但不改變整體結構。

改變 key 與改變 value 的分別

在 two-position 例子中固定 Q 和 K，把第二個 value [0,4] 改成 [0,8]。Attention weight 不變，因為計算 weight 沒有用到 V。每個混合 output 的第二個 coordinate 都會加倍。

現在還原 V，改變一個 key。Dot-product score 會改變，因此 softmax 可以重新分配兩個 value vector 的 mixture。無須解讀自然語言意思，已能分清比較角色與資訊角色。

第三個實驗，只改變一個 query row。這會改變該行的比較，但在後續處理之前，其他 query row 的 score 不變。這些受控 perturbation 是很好的小型測試。它們比背誦 Q、K、V 三個字母，更清楚說明每個 tensor 參與哪個階段。
