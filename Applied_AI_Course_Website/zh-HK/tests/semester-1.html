第一學期／考試

第一學期考試

兩小時 · 100 分 · 不參考筆記或 LLM 作答。

問題 1：language modeling 及 representations，15 分

以 “I go to school by bus” 解釋 next-token training，給出 shifted inputs/targets (5)。分辨 token IDs 與 embeddings，計算 cosine([3,4],[1,0]) 並解釋 (3)。Correct-token probabilities [.5,.25]，計 mean NLL 和 perplexity (2)。Label order [bus, train, bicycle]、probabilities [.6,.2,.2]，計 target train 的 NLL，解釋較低 loss 的意思 (5)。

問題 2：親手計算 attention，20 分

query 產生 unscaled scores [2,0]，d_head=4，values 為 [2,0] 及 [0,4]。計算 scaled scores、stable softmax 及 mixed output（10）。把第二個 key 當作 future position mask 掉，再計算（6）。即使 Q、K、V 來自同一 input，解釋它們的不同角色（4）。

問題 3：transformer architecture，20 分

B=2、T=128、d_model=256、H=8，給出 split Q/K/V、score、per-head output、merged output shapes (8)。計顯式 float32 score memory bytes 和 MiB (4)。解釋 pre-norm block 的 residual、normalization 和 positionwise MLP paths (4)。Standard MHA d_model=64、two-matrix MLP width256，忽略 biases/norms，計 attention+MLP matrix parameters，並指出一個會改變數量的 variant (4)。

問題 4：訓練 tiny transformer，20 分

寫 training-loop pseudocode，包含 shifted labels、causal masking、cross entropy、backward pass 及 optimizer update（8）。描述 future-token perturbation check 及 one-batch overfit diagnostic（6）。解釋 grouped train／dev splitting，以及低 training loss 為何不能證明 generalization（6）。

問題 5：generation 及 instruction following，15 分

比較 greedy、sampling 和 temperature (2)。給定 [.5,.3,.15,.05]，計 top-k=2 和 top-p=.7 distributions；top-p 取 cumulative mass 達到 threshold 的最短 sorted prefix (3)。解釋 KV cache 儲存甚麼、為何加速但沒有學到新 facts (4)。分辨 pretraining 與 instruction SFT (3)。解釋 fluent chain-of-thought 不能證明 correctness (3)。

問題 6：文字以外及實驗推理，10 分

比較 autoregressive image-token generation 和 diffusion (3)。解釋 recurrent state、vanishing gradients 和 LSTM/GRU gates 的用途 (3)。比較 encoder-only、decoder-only、encoder-decoder visibility (4)。

完成作答後，開啟完整評分指引

Q1（15）。 Inputs I/go/to/school/by，targets go/to/school/by/bus；每個 prefix 預測下一 token (5)。IDs 是 learned rows 的 indices (1)。Norm([3,4])=5，cosine=3/5=.6，比較方向 (2)。Mean NLL=(ln2+ln4)/2≈1.03972，perplexity≈2.82843 (2)。−ln(.2)=1.6094 nats。較低 loss 表示 observed target probability 較高，並非 factual truth 證明 (5)。

Q2（20）。 除以 sqrt(4)=2：[1,0]。stable exponents [1,.367879]，normalized [.731059,.268941]。output [1.462118,1.075764]。scaling 2 分、weights 4 分、output 4 分（共 10）。masked scores [1,-infinity]、probabilities [1,0]、output [2,0]（6）。Q 表示需要甚麼，K 用來評 compatibility，V 提供被混合的 payload；不同 projections 使它們能分工（4）。

Q3（20）。 Q/K/V [2,8,128,32]、scores [2,8,128,128]、head output [2,8,128,32]、merged [2,128,256] (8)。262144 elements×4=1048576 bytes=1 MiB (4)。x 先變成 x+Attention(LN(x))，再加 MLP(LN(x))；MLP 逐 position 處理，residual 保留直接 path (4)。Attention parameters=4×64²=16,384；MLP=2×64×256=32,768；合共49,152。GQA 改變 K/V count，gated MLP 多一個 matrix (4)。

Q4（20）。 shift batches；使用 causal mask 作 forward；把 position／vocabulary logits flatten，配對 aligned target IDs；cross entropy；zero gradients；backward；可選 clipping；optimizer step（8）。固定 parameters／eval mode 時，future perturbation 必須保持較早 logits 不變；微型 one-batch dataset 應能 overfit，作為 wiring diagnostic（6）。先 split source groups，再建 overlapping windows。memorization 及 leakage 可降低 training loss，卻沒有有用 generalization（6）。

Q5（15）。 Greedy 選最大 probability；sampling 按 distribution 抽樣；較低 temperature 令分布更尖 (2)。Top-k=2 保留 .5、.3，除以 .8 得 [.625,.375,0,0]。Top-p=.7 由同兩項達到 threshold，故結果相同 (3)。Cache 保留先前 keys/values，避免重算；parameters 不變 (4)。Pretraining 學 continuation；instruction SFT 用 desired responses 更新 parameters，通常只對 response tokens 計 loss (3)。Rationale 是 generated text，答案要獨立驗證並作 controlled comparison (3)。

Q6（10）。 Autoregression 預測 image tokens；diffusion 學 reverse/noise-prediction process (3)。Recurrence 更新 compressed state，重複 Jacobians 可能令 gradients 縮小；LSTM/GRU gates 控制 information flow (3)。Encoder self-attention 看完整 input；decoder 看 prefix；encoder-decoder 加上 target queries 對 source K/V 的 cross-attention (4)。
