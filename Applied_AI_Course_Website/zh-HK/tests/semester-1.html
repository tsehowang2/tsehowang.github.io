第一學期／考試

第一學期考試

兩小時 · 100 分 · 不參考筆記或 LLM 作答。

問題 1：language modeling 及 representations，15 分

用 “I go to school by bus” 解釋 next-token training，寫出 shifted inputs／targets（5）。區分 token IDs 與 embedding vectors，並解釋為何不可把 IDs 平均後當作 meanings（5）。probabilities 為 [.6,.2,.2]，target 為 train，計算 negative log likelihood 並解釋較低 loss 的意思（5）。

問題 2：親手計算 attention，20 分

query 產生 unscaled scores [2,0]，d_head=4，values 為 [2,0] 及 [0,4]。計算 scaled scores、stable softmax 及 mixed output（10）。把第二個 key 當作 future position mask 掉，再計算（6）。即使 Q、K、V 來自同一 input，解釋它們的不同角色（4）。

問題 3：transformer architecture，20 分

對 B=2、T=128、D=256、H=8，寫出 split Q／K／V、score、per-head output 及 merged output shapes（8）。計算明確儲存 float32 scores 所需的 bytes 及 MiB（4）。解釋 pre-normalized block 的 residual、normalization 及 positionwise MLP paths（4）。解釋 position information 與 causal mask 為何解決不同問題（4）。

問題 4：訓練 tiny transformer，20 分

寫 training-loop pseudocode，包含 shifted labels、causal masking、cross entropy、backward pass 及 optimizer update（8）。描述 future-token perturbation check 及 one-batch overfit diagnostic（6）。解釋 grouped train／dev splitting，以及低 training loss 為何不能證明 generalization（6）。

問題 5：generation 及 instruction following，15 分

比較 greedy decoding 與 sampling，包括 temperature（5）。解釋 KV cache 儲存甚麼，以及為何不用學新事實也能加快 decoding（4）。區分 pretraining 與 instruction SFT（3）。解釋流暢 chain-of-thought text 為何不能證明正確（3）。

問題 6：文字以外及實驗推理，10 分

比較 autoregressive image-token generation 與 diffusion generation（4）。描述 transformer 的一項限制，並設計 controlled tiny-model experiment 研究它（6）。

完成作答後，開啟完整評分指引

Q1（15）。 Inputs 為 I/go/to/school/by，targets 為 go/to/school/by/bus。每個 prefix 預測下一個 token（5）。IDs 是任意 row indices；vectors 是 learned representations。重新編排 IDs 時，同時排列對應 table rows，必須保留 meaning（5）。-ln(.2)=1.6094 nats。較低 loss 代表 observed target 得到較高 probability，不是真實性的證明（5）。

Q2（20）。 除以 sqrt(4)=2：[1,0]。stable exponents [1,.367879]，normalized [.731059,.268941]。output [1.462118,1.075764]。scaling 2 分、weights 4 分、output 4 分（共 10）。masked scores [1,-infinity]、probabilities [1,0]、output [2,0]（6）。Q 表示需要甚麼，K 用來評 compatibility，V 提供被混合的 payload；不同 projections 使它們能分工（4）。

Q3（20）。 Q/K/V [2,8,128,32]、scores [2,8,128,128]、head output [2,8,128,32]、merged [2,128,256]（8）。262144 elements 乘四 =1048576 bytes=1 MiB（4）。x 變成 x+Attention(LN(x))，再變成 x+MLP(LN(x))；MLP 逐個 position 運作，residual 保留直接路徑（4）。position 提供次序／位置；masking 防止 future leakage。兩者一般不能互相取代（4）。

Q4（20）。 shift batches；使用 causal mask 作 forward；把 position／vocabulary logits flatten，配對 aligned target IDs；cross entropy；zero gradients；backward；可選 clipping；optimizer step（8）。固定 parameters／eval mode 時，future perturbation 必須保持較早 logits 不變；微型 one-batch dataset 應能 overfit，作為 wiring diagnostic（6）。先 split source groups，再建 overlapping windows。memorization 及 leakage 可降低 training loss，卻沒有有用 generalization（6）。

Q5（15）。 greedy 選最大值；sampling 從 distribution 抽樣。把 logits 除以正 temperature：較低使 distribution 尖銳，較高使它平坦。兩者均不保證 globally best sequence（5）。cache 儲存較早 keys／values，避免重新計算；parameters 不變（4）。pretraining 學 continuation；instruction SFT 從期望 responses 更新 parameters，通常只對 response tokens 計 loss（3）。rationale 是生成 text；應用 controlled comparisons 獨立核對答案（3）。

Q6（10）。 autoregression 依次預測 discrete image tokens；diffusion 用 noise schedule 學 reverse／denoising process（4）。一個研究方法：把 synthetic dependency 移到越來越遠位置，固定 architecture、data count 及 training budget。報告 held-out accuracy、context constraints 及 tiny synthetic task 的限制。限制 2 分、controls／design 3 分、解讀 1 分（6）。
