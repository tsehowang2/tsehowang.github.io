Tool、function、workflow 與 agent

先嘗試作答，再開啟完整解答。預留 35–45 分鐘。

返回課堂10 分 · Q1 3 分 · Q2 3 分 · Q3 4 分
問題 1

區分 tool、workflow 及 agent。

顯示完整解答

tool 提供有 contract 的能力；workflow 大致固定 action 次序；agent 讓 model outputs 影響下一步 actions，但 enforcement 仍由 controller 掌握。

問題 2

計算兩張四元車票，加一張兩元車票。指出 proposal 及 observation。

顯示完整解答

提出 expression 2*4+1*2；經驗證 calculator 返回 10；final response 必須相符，並使用正確 price evidence。

問題 3

為 bounded calculator／config tool 指出 validation 及 safety tests。

顯示完整解答

拒絕 unknown tools、extra keys、把 booleans 當 strict integers、不支援 AST nodes、違反 numeric／size 限制及 wrong scope。domain-invalid config 不同於 invalid call schema；絕不可 eval model code。
