第二學期／考試

第二學期考試

兩小時 · 100 分 · 不參考筆記或 LLM 作答。

問題 1：adaptation，20 分

W shape [2048,4096]、LoRA rank 16，寫出 A／B shapes 及 parameter counts、dense count 及 adapter／dense ratio（8）。解釋 zero-update initialization（4）。比較 LoRA 與 QLoRA，不可假設 activations 為 four-bit（4）。列出 adapter reproduction 需保存的 dependencies（4）。

問題 2：fine-tuning 研究，15 分

新 adapter 把 exact tool JSON 從 75% 提升至 95%，但 incorrect tool arguments 從 5% 增至 20%。設計 controlled evaluation 及 release decision（8），指出兩個可能 dataset 原因（4），解釋為何 training loss 無法單獨解答問題（3）。

問題 3：agent controller，20 分

寫有界限 model／tool loop 的 pseudocode，包括 typed proposals、schema checks、scope checks、observations 及 terminal statuses（12）。解釋 step cap 為何不同於 call timeout（4）。解釋如何處理虛構但看似有效的 citation，以及只查 ID 不能證明甚麼（4）。

問題 4：MLOps 及 security，20 分

更換 embedding model 後，developers 沿用舊 vectors，並在 answer-cache keys 遺漏 tenant scope。解釋兩項 failures（6），提出 manifest／index migration 及 cache controls（8），並定義 regression tests 及 rollback unit（6）。

問題 5：performance 及 scaling，15 分

平均 arrival rate 是每秒 1.5 requests，平均在 system 停留 4 秒。估計平均 in-flight work 並列出假設（4）。區分 TTFT 與 end-to-end latency（3）。80% work 可 scalable、20% serial，計算理想四路 speedup（4）。解釋為何不能據此預測 production p95 或 communication cost（4）。

問題 6：capstone 答辯，10 分

agent 比固定 workflow 更昂貴，adapter 沒有可靠改善，而 retriever 可量度地改善 paraphrase questions。選擇 default release，並用會展示的 evidence 支持選擇（6）。指出兩項限制及一個聚焦的下一步 experiment（4）。

完成作答後，開啟完整評分指引

Q1（20）。 A=[16,4096]、B=[2048,16]。adapter=16×(4096+2048)=98,304；dense=2048×4096=8,388,608；ratio=.01171875=1.171875%（8）。一個 random factor／一個 zero factor 使 initial delta 為零，同時容許 gradient flow；兩者同為零可能阻止最初 factor learning（4）。LoRA 在 frozen base 上訓練 factors；QLoRA 額外 quantize frozen base，並在需要時保留較高 precision compute／state（4）。base／tokenizer revision、adapter config／weights、target modules、environment、training data／config 及 eval metadata；列出四種不同 dependencies（4）。

Q2（15）。 固定 model／base／context／tasks／decoding／tool validator，另設 prompt control；逐個 task 評 valid JSON 及 semantic argument correctness、invalid／forbidden actions 及 budgets；即使 syntax 改善，incorrect actions 若違反 gate 仍拒絕（8）。dataset 可能獎勵格式有效但 arguments 錯誤、欠 negative／refusal cases、有 wrong-version labels，或 paraphrases leakage；診斷兩項原因（4）。loss 只是對 labels 的 fit，有偏差／錯誤 labels 也能被成功學會（3）。

Q3（20）。 初始化 scope／state／budgets；在有限 steps 內，用受控 context 呼叫 planner；parse 及 validate proposal；final branch 驗證 citations／contract 後終止；tool action 驗證 name／schema／authority／limits，以 per-call enforcement 執行，記錄 normalized result；捕捉 typed failures；明確標示 budget 耗盡。六項有意義 controls／branches，每項 2 分（12）。blocking call 可在 loop 檢查前超過 wall time，需要真正 client timeout／process enforcement（4）。拒絕未授權／未觀察過的 IDs；現有 ID 仍不能證明 semantic entailment（4）。

Q4（20）。 不相容 coordinate systems 使舊 vectors 不適用；cache 遺漏 tenant scope 可暴露受限答案（6）。manifest 記錄 model／index／source compatibility，重建 versioned index、benchmark／switch／rollback；scope-aware cache keys、permission enforcement 及 invalidation（8）。tests 刻意配錯 embedding manifest，並作 cross-tenant requests；rollback 應恢復一致的 prompt／model／adapter／index／tool／corpus config，而非只有 weights（6）。

Q5（15）。 L=1.5×4=6，平均有六項在 system 內，假設 averages 穩定且 boundary 正確（4）。TTFT 直到第一個 output token；end-to-end 直到 response 完成，包括所有 application stages（3）。1/(.2+.8/4)=2.5 理想 speedup（4）。tail latency 依賴 variance／load／queueing，而 distributed work 有 communication／coordination；不能從這些 means 預測 p95（4）。

Q6（10）。 如 agent／adapter 沒有證實價值，應選符合條件的 retriever 配固定 workflow／base generator；保留 experimental branches 及 raw comparisons，報告 budget／quality／safety 及實際 negative results（6）。限制可包括 task-set size、small model capability、缺乏真正 users 或未測 high concurrency。下一步 experiment 必須用 control 及 metric 針對觀察到的 failure，例如在固定 context budget 下 rerank 未命中的 paraphrases（4）。
