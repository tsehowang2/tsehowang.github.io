環境設定與運算計劃

請先閱讀

網站使用靜態 HTML、CSS 及 JavaScript。閱讀、slides、搜尋、詳解、圖解及進度記錄都不需要安裝 Python 或付費服務。Code 會另外在你的電腦或 Colab 執行。

CPU 基礎路線

在 virtual environment 使用 Python 3.10–3.12，以取得較廣的 package 相容性。數值課節請安裝 NumPy。大部分早期 notebook 及 controller／evaluation 練習只需要 standard library 和 NumPy；Colab 通常已包含這些套件。

解壓完整課程 ZIP。根目錄包含 coursekit、data、notebooks 和 tests。在該目錄執行 python -m unittest discover -s tests -v。在 Colab 上載 ZIP，解壓至 /content/llm_course，再執行 bootstrap cell。該 cell 也會尋找已解壓的 llm_course_v2 資料夾。不要只上載 notebook 而欠缺支援檔案。

Model 下載與免費 GPU

第 12 週介紹小型 PyTorch transformer。短時間 CPU 執行用來核實 training 路徑；有 GPU 時，可在 Colab 進行較長實驗。後期 notebook 設有明確的安裝／下載 cell。免費 GPU 供應並不固定；請檢查獲分配的 device。斷線前，把 checkpoint 和報告儲存在暫時 runtime 以外的位置。

你的 GTX 1650 Super 屬可選資源。使用 nvidia-smi 檢查實際可用 VRAM。數值課節用 CPU，較大的 model 實驗用 Colab。不要假設所有 GPU 都支援 BF16、large batch 或 QLoRA kernel。先以 float32 CPU 核實正確性，或使用獲支援的 float16 GPU 執行。

可重現的 model 實驗

Notebook 中的 package 版本範圍只是起始約束，並非不可變 lockfile。記錄實際解析出的 Python、torch、transformers 和 accelerator 版本、model／tokenizer commit、data hash、seed 及 configuration。為可用環境儲存 lockfile。如果安裝 API 不同，請查閱最新官方文件。

Model lab 會下載小型 Qwen model 及／或 sentence embedding model。課程會解釋 QLoRA，但引導式 LoRA 試驗不要求 four-bit kernel。第 23 週 CUDA compilation 需要 nvcc。如果沒有，請閱讀 kernel 並記錄這個限制。

輸出

Bootstrap 會建立 runs 目錄。請使用 run ID 並保留實際輸出。虛構教學 fixture 規模很小，不能證明 production 品質或 model 的廣泛能力。

按階段閱讀

第 1–5 週：筆記中的日常句子例子及數學先備知識；外部閱讀屬選讀。第 6–11 週：R04 attention 和 transformer 圖解，以及官方 Stanford CS224N 材料 https://web.stanford.edu/class/cs224n/。第 12–16 週：R04 training／architecture、R09 instruction／reasoning 例子、R10 受控 reasoning 研究、R21 generative-model 直覺。第 17–21 週：R06 RAG、R07 embedding、R08 vector database、R24 ANN、R25 lexical retrieval。第 22–23 週：R16 CUDA thread hierarchy、R19 profiling、R26 memory-aware attention。第 24–26 週：R12 LoRA、R13 QLoRA、R14 adapter configuration、R15 preference。第 27–32 週：R11 action／observation、R20 tracking、R18 delivery recipe，以及相關 model／runtime 文件。閱讀材料用來延伸 lecture；先理解基礎例子，才閱讀 research paper。

關於本課程

獨立原創自學材料，與 Stanford 或 NTU 並無隸屬關係，也不提供其證書。教學方法結合直覺講解、機制、實作及受控實驗。導師公開材料的連結屬可選參考，並非複製其 lecture 內容。

驗證與限制

全部 32 份 notebook 及配套 script 已檢查 syntax。27 條可用 CPU 執行的 tutorial 路徑，以 Python 3.13 成功執行，需要時使用 NumPy 2.5.4。23 項支援元件 contract test 通過。上述 CPU 執行期間，已停用可選的真實 model 區塊。Extraction API smoke test 及 controller fixture 已執行；它們並非 LLM inference benchmark。

這次修訂環境沒有執行真實 tiny-transformer training（第 12 週）、embedding／Qdrant（第 18 週）、CUDA compilation／profiling（第 23 週）、LoRA training（第 26 週）及真實 model planning（第 28 週）。第 13、17、20 週的可選 model 路徑也沒有執行。Code 已檢查 syntax；package／device／model 相容性及 model 品質須在你的 runtime 驗證。沒有把 fixture 結果當作已訓練 model 的結果。發放的 notebook output 為空，亦不包含驗證 run 和 checkpoint。
