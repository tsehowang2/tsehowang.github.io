目前 embedding recipe

使用 intfloat/multilingual-e5-small 時，每條 query 前加 query:，每個 passage 前加 passage:，中文亦一樣。output 是 384 dimensions，model input limit 是 512 tokens；prefixes 和 special tokens 亦佔用這個 budget。embedding recipe 改變後，重新建立 collection。

在 vector database 之前，semantic search 只是一列 document vectors 加一個 query vector。從你能自行判斷 relevance 的 school-handbook 句子開始。sentence embedding model 是為 sequence representation 訓練的，並非隨便一張 hidden-state table。

# Invented normalized geometry to inspect exact search, NOT model embeddings.
texts = ['The school bus leaves at eight.', 'Lunch starts at noon.', 'The library closes at five.']

import numpy as np
vectors = np.array([[1.0, 0.0], [0.0, 1.0], [0.6, 0.8]])
q = np.array([1.0, 0.0])
scores = vectors @ q
print('Illustrative ranking:', np.argsort(-scores).tolist())

計算 contrastive 例子

使用第 17 週講義中設計的 score matrix。diagonal 是已標示的 positives。執行前先預測 mean loss，再比較另一個有用 passage 被錯當成 negative 時的 Q1 loss。這個 cell 只計算 objective，並不會 training embedding model。

程式步驟 2

Python 
import math
scores = [[2.0, 1.0, 0.0], [0.0, 2.0, 1.0], [1.0, 0.0, 2.0]]

def candidate_probs(row):
    exps = [math.exp(x - max(row)) for x in row]
    return [x / sum(exps) for x in exps]
probs = [candidate_probs(row) for row in scores]
losses = [-math.log(row[i]) for i, row in enumerate(probs)]
print('Candidate probabilities:', probs)
print('Mean contrastive loss:', sum(losses) / len(losses))
print('False-negative example Q1 loss:', -math.log(candidate_probs([2.0, 2.0, 0.0])[0]))

Cosine scores 與 temperature

先前的 [2,1,0] 是教學 logits。這次 input 是可能出現的 cosine scores，先除以選定 temperature，再做 softmax。這個固定例子經 rescale 後 loss 較低，並不代表 embedding model 已改善。

程式步驟 4

Python 
import math
cosines = [0.8, 0.6, 0.2]

def probs_at_temperature(xs, tau):
    logits = [x / tau for x in xs]
    m = max(logits)
    e = [math.exp(x - m) for x in logits]
    return [x / sum(e) for x in e]
for tau in [1.0, 0.05]:
    p = probs_at_temperature(cosines, tau)
    print('tau', tau, 'p', p, 'positive loss', -math.log(p[0]))
assert -math.log(probs_at_temperature(cosines, 0.05)[0]) < -math.log(probs_at_temperature(cosines, 1.0)[0])
