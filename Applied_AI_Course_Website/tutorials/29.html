What to do and what to submit

Compute: CPU; no downloads. Read lecture 29 first. Allow two hours for the guided path and two for independent work.

Before execution: Inspect one complete input/output record before running the full path. Predict a normal result and one failure status.

Guided path: read one cell, identify the inputs and expected shape or status, and write a prediction. Run it and compare every relevant output with the prediction. If it differs, inspect the smallest intermediate result before changing anything else. Re-run from a clean kernel to check hidden-state dependence.

Independent work: Change one controlled factor, preserve raw outputs and explain the result. Use the lecture readiness check and capstone milestone to define the task; do not claim fixture success establishes production readiness.

Submit: a concise notebook/report with your prediction, actual output, controlled comparison, interpretation and one limitation. Include environment details when packages or devices matter. An unexecuted GPU/model path must be labeled unexecuted. Use the ten-point tutorial rubric in the syllabus.

The next cell starts a loopback extraction API as a subprocess and stops it afterward. It is not an LLM inference benchmark. Use a free port if another service occupies 8000; do not measure an unrelated server.

Code step 2

Python 
import subprocess,urllib.request,urllib.error
process=subprocess.Popen([sys.executable,'-m','coursekit.server'],cwd=COURSE,stdout=subprocess.DEVNULL,stderr=subprocess.DEVNULL)
try:
    for attempt in range(30):
        if process.poll() is not None: raise RuntimeError('Server exited; check whether port 8000 is occupied.')
        try:
            with urllib.request.urlopen('http://127.0.0.1:8000/health',timeout=1) as response:
                assert json.load(response)['status']=='ok'
            break
        except (OSError,AssertionError): time.sleep(.1)
    else: raise RuntimeError('Server did not become healthy')
    payload=json.dumps({'question':'default request timeout','version':'2'}).encode()
    timings=[]
    for _ in range(20):
        start=time.perf_counter()
        request=urllib.request.Request('http://127.0.0.1:8000/ask',data=payload,headers={'Content-Type':'application/json'})
        with urllib.request.urlopen(request,timeout=3) as response: result=json.load(response)
        timings.append((time.perf_counter()-start)*1000)
    assert 'timeout-v2' in result['citations'] and 'timeout-v1' not in result['citations']
    ordered=sorted(timings)
    print('Local extractor median ms',ordered[len(ordered)//2],'nearest-rank p95',ordered[math.ceil(.95*len(ordered))-1])
    (RUNS/'week29_latency.json').write_text(json.dumps({'milliseconds':timings,'result':result,'service':'local extractor'},indent=2))
finally:
    process.terminate();process.wait(timeout=5)

Continuous batching admission trace

B finishes after one decode step and C enters at the next step while A continues. This is a scheduling illustration; it does not implement PagedAttention or measure a serving runtime.

Code step 3

Python 
requests={'A':3,'B':1};completed=[];trace=[]
for step in range(1,4):
    if step==2:requests['C']=2
    active=list(requests)
    for request in active:
        requests[request]-=1
        if requests[request]==0:completed.append(request)
    trace.append((step,active,completed.copy()))
    requests={key:value for key,value in requests.items() if value>0}
assert trace[1][1]==['A','C'] and set(completed)=={'A','B','C'}
print('Decode-step scheduling fixture:',trace)
