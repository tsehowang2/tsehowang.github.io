When you run this notebook, also download and extract the full course pack for the support files and teaching data. You can read the support implementations here.

What to do and what to submit

Tutorial: construct context-conditioned targets, include insufficiency cases, split by group and calculate LoRA shapes/counts.

Independent experiment: write an error-based intervention proposal. Create a separate reviewed narrow-task train set and dev split, with provenance and manual audit. Aim for 100–300 clean examples if feasible; a smaller pilot must make a narrower claim. Inspect target/prompt truncation with the real tokenizer before training.

Expected: train/dev groups do not overlap; rank-8 update for 4096² has 65,536 trainable factors, .390625% of the dense matrix.

Debug: source-backed labels may still be incomplete or stylistically inconsistent. Synthetic examples require review; do not recycle final test labels.

Submit: data card, split/audit script, examples, parameter/memory worksheet and a hypothesis specifying expected improvements and possible regressions.
