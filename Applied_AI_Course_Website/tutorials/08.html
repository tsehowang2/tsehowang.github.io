What to do and what to submit

Tutorial: produce per-task records with ungraded manual fields and reproduce recall/hit/RR arithmetic. Run paired bootstrap on illustrative data, then replace it with actual matched outputs.

Independent experiment: grade the chosen systems blind to configuration where feasible; add five original adversarial cases. Define primary metric and slice reports. Check whether source/task grouping makes an individual-task bootstrap optimistic.

Expected: gold-empty retrieval recall is not applicable; all parse/time/tool failures remain visible. A two-task improvement is not automatically significant.

Debug: do not average null fields as zeros or silently drop failures. Confirm that each output aligns to the correct task ID.

Submit: RAG v1, raw/graded records, uncertainty/error analysis, reproducibility manifest, semester report and exam 1 corrections. Exam week replaces ordinary project time.
