Read the walkthrough, inspect the code, then run the notebook when you are ready.

When you run this notebook, also download and extract the full course pack for the support files and teaching data. You can read the support implementations here.

What to do and what to submit

Tutorial: create and verify a corpus manifest, start the localhost extraction service, check health and API scope, measure end-to-end timings and stop the child process.

Independent experiment: replace the answerer with the chosen real generator behind the same contract; record all dependent revisions. Measure representative short/long inputs at multiple concurrency levels with failures and warm/cold states. Use enough requests to discuss p95 uncertainty honestly.

Expected: wrong manifest rejected; v2 request excludes v1 citations. The bundled 20-call extractor timing is not LLM throughput evidence.

Debug: port conflicts can query the wrong server; verify process ownership/health and change the port if needed. Health is not the same as model readiness.

Submit: API instructions, actual model-serving latency report, environment/manifest and deployment control plan. Public hosting is optional; local deployment claims must be labeled local.

The next cell starts a loopback extraction API as a subprocess and stops it afterward. It is not an LLM inference benchmark. Use a free port if another service occupies 8000; do not measure an unrelated server.

import subprocess,urllib.request,urllib.error
process=subprocess.Popen([sys.executable,'-m','coursekit.server'],cwd=COURSE,stdout=subprocess.DEVNULL,stderr=subprocess.DEVNULL)
try:
    for attempt in range(30):
        if process.poll() is not None: raise RuntimeError('Server exited; check whether port 8000 is occupied.')
        try:
            with urllib.request.urlopen('http://127.0.0.1:8000/health',timeout=1) as response:
                assert json.load(response)['status']=='ok'
            break
        except (OSError,AssertionError): time.sleep(.1)
    else: raise RuntimeError('Server did not become healthy')
    payload=json.dumps({'question':'default request timeout','version':'2'}).encode()
    timings=[]
    for _ in range(20):
        start=time.perf_counter()
        request=urllib.request.Request('http://127.0.0.1:8000/ask',data=payload,headers={'Content-Type':'application/json'})
        with urllib.request.urlopen(request,timeout=3) as response: result=json.load(response)
        timings.append((time.perf_counter()-start)*1000)
    assert 'timeout-v2' in result['citations'] and 'timeout-v1' not in result['citations']
    ordered=sorted(timings)
    print('Local extractor median ms',ordered[len(ordered)//2],'nearest-rank p95',ordered[math.ceil(.95*len(ordered))-1])
    (RUNS/'lab13_latency.json').write_text(json.dumps({'milliseconds':timings,'result':result,'service':'local extractor'},indent=2))
finally:
    process.terminate();process.wait(timeout=5)
