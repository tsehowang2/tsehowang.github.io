What to do and what to submit

Compute: CPU; no downloads. Read lecture 24 first. Allow two hours for the guided path and two for independent work.

Before execution: Inspect a prompt containing distractors and its concise reviewed answer, including the cross-version record.

Guided path: read one cell, identify the inputs and expected shape or status, and write a prediction. Run it and compare every relevant output with the prediction. If it differs, inspect the smallest intermediate result before changing anything else. Re-run from a clean kernel to check hidden-state dependence.

Independent work: Audit every target and citation; expand independent question families and keep missing-answer and comparison cases in grouped splits.

Submit: a concise notebook/report with your prediction, actual output, controlled comparison, interpretation and one limitation. Include environment details when packages or devices matter. An unexecuted GPU/model path must be labeled unexecuted. Use the ten-point tutorial rubric in the syllabus.

for t in json.loads((COURSE / 'data/queries.json').read_text(encoding='utf-8')):
    candidates = [d for d in docs if t['version'] == 'all' or d['version'] == t['version']]
    context = '\n'.join(('[' + d['id'] + '] version=' + d['version'] + ' ' + d['text'] for d in candidates))
    target = {'answer': answers[t['id']], 'citations': t['relevant']}
    records.append({'task_id': t['id'], 'group': t['group'], 'version': t['version'], 'messages': [{'role': 'user', 'content': 'Use this evidence only:\n' + context + '\nQuestion: ' + t['question']}, {'role': 'assistant', 'content': json.dumps(target)}]})
assert len(records) == 12 and any((r['version'] == 'all' for r in records))
groups = sorted({r['group'] for r in records})
random.shuffle(groups)
held_groups = set(groups[:2])
train = [r for r in records if r['group'] not in held_groups]
dev = [r for r in records if r['group'] in held_groups]
assert not {r['group'] for r in train} & {r['group'] for r in dev}
assert train and dev
(RUNS / 'week24_train.json').write_text(json.dumps(train, indent=2), encoding='utf-8')
(RUNS / 'week24_dev.json').write_text(json.dumps(dev, indent=2), encoding='utf-8')
print('Tiny demonstration split', len(train), len(dev), 'held groups', held_groups)
