Hardware and cuda

Read the walkthrough, inspect the code, then run the notebook when you are ready.

Lecture 09Lecture 10Download notebookOpen in Colab ↗

When you run this notebook, also download and extract the full course pack for the support files and teaching data. You can read the support implementations here.

What to do and what to submit

Tutorial: calculate memory, inspect actual GPU properties, compile vector_add when nvcc is available, test n=1/257/1048576 and profile PyTorch work with synchronization.

Independent experiment: compare at least three array sizes and block sizes, retaining bounds checks. Separate kernel timing from data-transfer timing. Repeat enough runs for a median/spread; the bundled executable prints an average that you should extend or repeat externally. Profile one short model forward pass and identify an operator/memory bottleneck.

Expected: cache example is 96 MiB; vector-add output matches CPU within tolerance. Small kernels may be dominated by launch overhead.

Debug: no nvcc means the C++ task was not run; no GPU means no GPU measurement. Unsupported dtype/toolchain errors require a compatible runtime, not fabricated timing.

Submit: kernel, correctness cases, device/software record, timing table, trace and bottleneck explanation. A CPU-only theoretical worksheet leaves the measured CUDA portion incomplete.

import torch
from torch.profiler import profile,ProfilerActivity
print('torch',torch.__version__,'CUDA runtime',torch.version.cuda)
if torch.cuda.is_available():
    print(torch.cuda.get_device_name(0),torch.cuda.get_device_properties(0).total_memory)
    x=torch.randn(1024,1024,device='cuda');y=torch.randn_like(x)
    for _ in range(10): z=x@y
    torch.cuda.synchronize();torch.cuda.reset_peak_memory_stats()
    start,stop=torch.cuda.Event(enable_timing=True),torch.cuda.Event(enable_timing=True)
    times=[]
    for _ in range(20):
        start.record();z=x@y;stop.record();stop.synchronize();times.append(start.elapsed_time(stop))
    assert torch.allclose(z.cpu(),x.cpu()@y.cpu(),atol=.003,rtol=.003)
    with profile(activities=[ProfilerActivity.CPU,ProfilerActivity.CUDA],record_shapes=True,profile_memory=True) as prof:
        z=x@y;torch.cuda.synchronize()
    prof.export_chrome_trace(str(RUNS/'lab05_trace.json'))
    print(prof.key_averages().table(sort_by='self_cuda_time_total',row_limit=8))
    print('Median kernel interval ms',sorted(times)[len(times)//2],'peak allocated bytes',torch.cuda.max_memory_allocated())
else: print('GPU profiling NOT executed. Memory arithmetic is not a hardware measurement.')
