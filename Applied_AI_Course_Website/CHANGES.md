# Second-edition changes

The first 16 weeks now teach language models and transformers before application development. Each topic begins with ordinary examples, then adds numerical reasoning and deeper study. School/travel sentences carry the early explanations.

The 32 lectures contain about 36,000 words and 401 HTML slides, with complete notes below each presentation. There are now 32 single-week tutorials, 96 aligned questions and worked answers, revised diagnostic checks and a transformer-only first-semester exam. The documentation-assistant milestones start in week 17.

Five new beginner illustrations join the nine existing interactive mechanisms. The visual design and static GitHub Pages publishing route are retained.
