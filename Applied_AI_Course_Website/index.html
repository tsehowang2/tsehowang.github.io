How the course works

A clear path from
intuition to evidence.

Each week connects an explanation, a worked example, a tutorial and a short test. Interactive visual lessons help you inspect what changes, rather than just memorize the terminology.

Your project grows with you: first a search baseline, then a grounded assistant, then tested tools and a reproducible release.
